# 签到与时长状态矩阵

## 1. 基本规则

- 公开签到台始终允许启用账号提交签到和签退，包括非值班日及时段外提交。
- 普通成员的签到和签退为待审核；部长、会长和管理员自动通过。
- 管理员可以分别开启“强制值班日”和“强制值班时段”。两个开关默认关闭。
- 签到发生时会保存值班日、值班时段及两个限制开关的快照，之后修改设置不会改变历史记录。
- 同一成员同一天完成签退后可以再次签到，每一组签到至签退独立计算。
- 同日多段记录的实际时间区间不得重叠；前一段签退时间等于后一段签到时间时视为相邻时段，允许保存。
- 手动补录和修改的签到、签退时间不得晚于当前时间 5 分钟以上。

## 2. 有效状态

| 条件 | 有效状态 | 分钟数 | 有效小时 |
| --- | --- | --- | --- |
| 签到或签退被驳回 | `INVALID` | 0 | 0 |
| 开启强制值班日且签到日不是值班日 | `INVALID` | 0 | 0 |
| 开启强制值班时段且签到不在时段内 | `INVALID` | 0 | 0 |
| 没有签退或签退状态为未提交 | `INCOMPLETE` | 0 | 0 |
| 签到或签退仍待审核 | `PENDING` | 0 | 0 |
| 已通过但签退不晚于签到 | `INVALID` | 0 | 0 |
| 签到和签退均通过且未触发已开启的限制 | `VALID` | 实际分钟 | 四舍五入后的小时 |

限制开关关闭时，对应的值班资格只作为审核参考，不直接阻止记录计时。

## 3. 小时舍入

有效分钟按签到至签退的实际时间差计算，有效小时按最近整数小时计算：

| 实际分钟 | 有效小时 |
| --- | --- |
| 29 | 0 |
| 30 | 1 |
| 89 | 1 |
| 90 | 2 |

每条记录先独立舍入，再由统计页面逐条相加；培训时长按培训记录中的小数时长另行累计。

培训参与记录只以 `duration_hours` 为准：正时长计入培训次数与时长，零时长保留但不计入汇总。历史出席、缺席、请假状态不再参与判断。

## 4. 审核与修改

- 驳回必须填写原因；通过操作不得把说明写入驳回原因字段。
- 批量通过会同时处理所选记录中仍为待审核的签到和签退，不重复处理相同记录编号。
- 部长的审核列表不包含本人记录。
- 部长只能修改或删除本周普通成员及部长记录，且不能手动补录。
- 会长和管理员可以补录记录；所有手动修改均需填写原因并写入操作日志。
- 补录允许选择非值班日及时段外时间，是否计时由补录时保存的规则快照与最终状态共同决定。
- 手动修改默认保留原记录的值班日、时段和强制策略快照；会长或管理员可显式选择按当前设置重新评估，部长无此权限。
- 手动修改会清除已经失效的旧审核人、审核时间和驳回原因，由操作日志保留修改历史。
