# 后台页面视觉验收记录

## 1. 验收范围

本轮在不改变淡蓝色后台整体风格和业务功能的前提下，检查并精修以下页面：

- 培训记录
- 统计汇总
- 系统设置
- 数据与备份
- 个人资料
- 维修事务
- 操作日志

测试使用一次性 SQLite 数据库和虚构数据，包含超长培训标题、地点、说明、维修设备名称和操作日志。正式数据库、备份文件和成员资料未被读取或修改。

## 2. 重点修复

### 培训记录

- 场次列表的长标题限制为两行，元数据省略且不会撑宽布局。
- 768px 以下改为上下工作区，避免列表与详情互相挤压。
- 390px 下参与名单改为语义化信息卡，姓名、时长、备注和操作保持完整可读。
- 详情工具按钮在窄屏独立成行，所有图标按钮均有可访问名称。
- 编辑弹窗补齐字段名称，打开后自动聚焦培训标题。

### 系统设置

- 值班时段在手机端按“排序与删除、开始与结束、时长与状态”三层排列。
- 上移、下移和删除按钮补齐可访问名称，装饰图标不重复朗读。
- 时段重叠等校验错误使用 `role="alert"` 即时播报。

### 后台外壳与其他页面

- 后台紧凑导航断点由 760px 调整为 900px，修复 768px 下两级侧栏挤压主内容的问题。
- 维修编辑、维修回收和日志详情按钮补齐可访问名称。
- 主导航选中标记收回导航项内部，消除导航容器自身的横向滚动宽度。
- 统计、数据与备份、个人资料、维修事务和日志保留现有信息架构，仅完成溢出与语义复核。

## 5. 设计约束

- 保留当前淡蓝色、白底和紧凑后台结构，不增加装饰性页面区块。
- 保持组件按业务模块拆分；本轮新增样式位于独立的 `admin-detail-polish.css`。
- 不将页面说明替代字段标签，不使用仅靠占位符表达含义的新增表单字段。
- 动画继续遵守系统的减少动态效果设置。
