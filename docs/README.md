## 目录维护

新增内容优先更新已有主题文档，不另建“当前工作区”“最终版”等平行副本。长期规则写入 AGENTS.md，进度写入 DEV_STATE.md，验收结果写入 verification，发行变化写入 releases。

`design-previews/`、`docs/admin-layout-v2/`、`docs/full-ui-design-v1/`、`docs/layout-v2/` 和 `docs/frontend-design*` 是本地旧设计草稿，已被 Git 忽略，不参与运行或构建。2026-09-07 的删除因执行策略拒绝而未完成。`tasks/` 中的测试证据、运行数据及发行文件也不进入文档目录或 Git。
