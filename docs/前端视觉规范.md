# 前端视觉规范

本规范用于计算机协会本地管理系统的后台、登录页和签到台。界面应保持克制、清晰、适合普通办公显示器长期使用。后台的视觉定位是“安静、精确的本地工作台”：通过稳定结构、清晰文字和少量协会蓝建立识别，不依赖装饰性卡片、营销式标题或高饱和效果。

## 设计原则

1. 业务信息优先，装饰不能争夺注意力。
2. 协会蓝用于品牌、主操作、链接和当前选中状态。
3. 普通页面使用中性灰白画布与白色工作面板。
4. 状态必须同时使用文字和颜色表达。
5. 动效用于说明状态变化，不让大面积内容反复移动。
6. 每个页面只突出一个主要工作区和一个主要操作，低频内容不得长期占据首屏。
7. 结构元素必须表达真实层级；分隔线、标签和路径不能只用于装饰。

## 后台视觉结构

后台保持“固定导航 + 页面标题 + 主工作区”的稳定骨架。页面切换时导航、标题基线和内容起点不得跳动。

- 导航用于定位模块，不重复展示页面说明和业务统计。
- 页面标题用于确认当前位置，紧邻的日期、范围或状态属于元数据，不写成长段副标题。
- 筛选、表单和表格使用连续工作面，不拆成多层悬浮卡片。
- 卡片仅用于重复业务实体、关键待办或确实需要边界的工具，不嵌套卡片。
- 同一页面超过三个同权重操作时，应通过分组、菜单或明确的主次关系降低噪声。

## 色彩

| 用途 | 变量 | 使用范围 |
| --- | --- | --- |
| 主文字 | `--ink-950` | 标题、关键数值 |
| 正文 | `--ink-800` | 表格、表单、普通内容 |
| 次要文字 | `--ink-500` / `--ink-600` | 时间、说明、元数据 |
| 画布 | `--admin-canvas` | 后台内容区 |
| 面板 | `--admin-surface` | 表格、表单和内容面板 |
| 品牌蓝 | `--admin-blue` | 主按钮、选中态、链接 |
| 品牌浅蓝 | `--admin-blue-soft` | 当前命令参数、选中建议、轻量焦点背景 |
| 焦点环 | `--focus-ring` | 键盘焦点和命令输入活动状态 |
| 成功 | `--green-700` | 已完成、有效、启用 |
| 待处理 | `--amber-700` | 待审核、处理较久 |
| 异常 | `--red-700` | 未签退、失败、危险操作 |

不要用蓝色表达所有信息。普通边框、表头和筛选区应优先使用中性灰色。新增视觉状态必须先归入语义色角色，不在业务组件中散落一次性十六进制颜色。

## 字体层级

| 内容 | 字号 |
| --- | --- |
| 页面标题 | 28-32px |
| 模块标题 | 17-18px |
| 正文和表格数据 | 13-14px |
| 表格表头 | 12px |
| 表单标签 | 12px |
| 状态标签 | 12px |
| 辅助说明 | 12px |
| 命令输入 | 18-20px |
| 命令建议主文本 | 14-15px |

中文正文使用 `--font-sans`，时间、编号和数字矩阵可使用 `--font-mono`。可见文字不得低于 12px，不能通过缩小字号制造精致感。

## 间距和尺寸

- 页面内容间距：20-24px。
- 面板内部间距：12-20px。
- 表单字段间距：10-16px。
- 标准按钮高度：40px。
- 小按钮高度：34px。
- 图标按钮：36px。
- 表格普通行高：56px。
- 命令输入框：56px，窄屏不得低于 48px。
- 命令建议行：52-58px，内容换行时允许自然增高。
- 页面最大内容宽度：1420px。

固定格式界面必须使用稳定尺寸或网格约束，避免文字和状态变化导致布局跳动。

## 圆角和阴影

- 按钮、输入框和小菜单：4-6px。
- 面板和表格：7px。
- 模态框：7-8px。
- 常规业务面板只使用轻微阴影。
- 不使用整块面板悬浮或大面积发光效果。
- 不嵌套装饰性卡片。

## 按钮层级

- `primary`：页面唯一或最重要的提交操作。
- `secondary`：导入、筛选、刷新、取消等次要操作。
- `text`：协议预览、清除筛选等低权重操作。
- `danger` / `danger-text`：删除、清空等不可逆操作。
- 多个低频行操作应放入“更多”菜单。
- 同一操作组中的导入、导出和新增按钮必须使用一致高度、图标尺寸、焦点环和按压反馈；颜色只用于表达层级，不按页面各自换色。
- 按钮文案使用明确动作，不附加“点击这里”“立即体验”等说明性文字。

纯图标按钮必须有 `title` 和 `aria-label`。存在常见图标时不使用文字胶囊代替。

## 状态表达

- 成功：绿色标签或边线，同时显示“有效”“完成”等文字。
- 待处理：琥珀色，并显示待处理数量或原因。
- 异常：红色，并提供下一步操作。
- 普通信息：中性灰。
- 无数据：显示明确空状态，不留下空白面板。

## 表格和矩阵

- 表头使用中性灰底，正文保持白底。
- 长表格固定表头。
- 横向矩阵可固定关键左列和右侧合计列。
- 行悬浮只改变浅背景，不让整行位移。
- 数值热力底色必须克制，并提供图例。
- 操作列保持稳定宽度。

## 页面标题

后台页面使用统一结构：

```text
页面标题                         [次要操作] [主要操作]
日期 / 范围 / 状态等必要元数据
```

用途明确的页面不显示解释性副标题。“今日”页面使用日期和当前角色作为元数据；后台页面不重复显示英文分类眉题。标题和操作在窄屏允许分行，但主要操作不得被挤出视口。

## 后台命令工作区

后台首页命令台是快速进入业务流程的主工作区，不采用黑色终端、独立悬浮控制台或多层卡片。首页使用居中的任务舞台和底部稳定输入区；命令建议向上展开，并在面板顶部用真实路径说明当前正在填写动作、对象还是参数。

```text
                 协会会徽
              今天要处理什么？
           [角色相关快捷操作，最多三项]

┌ 命令路径  查看 › 值班记录 › 时间范围 ┐
│ 本周              补全当前参数        │
│ 待审核            补全当前参数        │
└──────────────────────────────────────┘
[/ 查看 值班记录                         执行]
```

### 命令输入

- 输入框在首页内容区底部居中，桌面端使用完整可用宽度，不做窄小搜索胶囊，也不覆盖后台导航、Toast 或弹窗。
- `/` 固定使用等宽字体和品牌蓝，用户输入使用正文高对比度颜色。
- 唯一尾字补全显示在当前文字之后，使用次要文字色，视觉强度约为已输入文字的 35%-45%，不得看起来像已经输入。
- 输入框右侧只保留一个明确执行按钮；命令不完整时按钮禁用但不隐藏，避免布局移动。
- 输入框聚焦使用可见焦点环和轻量阴影；整体位移不超过 1px，不使用大面积发光。

### 命令路径

- 已确认节点使用正文色，当前活动节点使用品牌蓝和短下划线，尚未填写节点使用次要文字。
- 节点之间使用简单箭头或尖括号图标分隔，不使用带底色的文字胶囊。
- 路径只展示语法层级，不重复描述执行结果；超出一行时允许水平滚动，不压缩到无法阅读。
- 光标移动到前一个参数时，当前节点强调应立即同步，不播放整条路径重入动画。

### 建议面板

- 面板在输入框正上方与其等宽，最大高度 320px，仅内部滚动；边框和阴影保持轻量。
- 建议行采用“当前参数 / 参数类型 / 直接结果”三段结构，不重复整条命令。
- 键盘活动项使用浅蓝背景和左侧 2px 品牌蓝指示线；鼠标悬停使用中性浅灰，两者不能混为同一状态。
- 参数类型是低权重文字，不做一排彩色标签。只有完整命令才显示“打开”“预填”“需确认”等执行等级。
- 没有合法建议时显示具体参数要求或错误原因，不使用只有“没有结果”的空白状态。

### 命令状态

| 状态 | 视觉要求 |
| --- | --- |
| 普通搜索 | 中性边框，显示功能结果，不展示命令路径 |
| 等待参数 | 当前路径节点和建议面板使用浅蓝强调 |
| 命令完整 | 执行按钮启用，输入框边框使用品牌蓝，显示一行结果摘要 |
| 参数错误 | 错误参数使用红色下划线，输入框高度不变，错误文字显示在下方 |
| 执行中 | 执行按钮显示进度并锁定重复操作，建议面板保持稳定 |
| 执行完成 | 使用 1.5-2.5 秒 Toast，不在首页增加长期成功卡片 |

命令层级切换使用 180-340ms 淡入和不超过 10px 位移；活动轨道可使用短促缓动，但建议行不逐项飞入。启用 `prefers-reduced-motion` 时取消位移并缩短非必要过渡。

## 动效

- 页面切换：轻微淡入和不超过 4px 的位移。
- 菜单和弹窗：短距离展开，时长 140-220ms。
- 按钮：允许 1px 的按压或悬浮反馈。
- 禁止表格逐行飞入、面板整体上浮和循环装饰动画。
- 所有动效必须支持 `prefers-reduced-motion`。

## 响应式

- 1180px 以下：筛选区使用两列网格，页头操作允许换行。
- 900px 以下：后台导航切换为抽屉，主内容获得完整可用宽度。
- 680px 以下：筛选区和表单改为单列。
- 680px 以下：命令建议隐藏次要结果说明，保留参数名称、类型和当前选中状态；路径轨道允许水平滚动。
- 数据表格和排班矩阵在自身容器内滚动，不让页面整体产生横向滚动。
- 验收尺寸至少包含 1440、1180、900、680 和 520px，并检查 Windows 125%、150% 与浏览器 200% 缩放。

## 隐私

- 公共签到台只显示学号后四位。
- 维修联系电话默认脱敏，按需临时展开。
- 不在页面上长期保留上一位签到成员的身份信息。
- 敏感操作必须使用应用内确认弹窗。
- 命令建议不枚举真实姓名、完整学号、电话和维修编号；敏感参数不能通过尾字补全暴露。

## CSS 文件职责

- `tokens.css`：全局色彩、字体、间距和基础变量。
- `components.css`：通用按钮、表单、表格和面板结构。
- `admin-shell.css`：后台主导航、二级导航和内容区布局。
- `admin-details.css`：具体业务页面的结构与细节。
- `admin-interactions.css`：菜单、筛选标签等交互组件。
- `admin-theme.css`：唯一的后台最终视觉层，不再重复定义两套主题。
- `today.css`、`schedule.css`：对应复杂页面的页面级布局。
- `command-center.css`：后台首页命令工作区、欢迎区、建议面板和输入区视觉。

新增样式前应先确认归属文件，避免使用文件末尾覆盖前面同一选择器的方式修复问题。
