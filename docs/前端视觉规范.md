# 前端视觉规范

适用于初始化、登录、签到台和后台。当前进度见 [DEV_STATE.md](../DEV_STATE.md)；命令行为见 [命令契约](后台命令台设计规范.md)。本文只维护展示约束，历史验收见 [多主题记录](verification/多主题前端验收记录.md)。

## 三主题与结构

- Classic 为默认与失败回退；Editorial、Spatial 使用各自变量和布局。共用业务状态、权限、接口及基础控件，不克隆业务逻辑。
- 保留 Classic 侧栏工作台、Editorial 顶部导航与页边分区、Spatial 顶部导航与工作面工具带的结构差异，不强制统一骨架或仅换颜色。主题样式限定作用域，首次加载及连续切换后均须成立。
- 业务信息优先，保持导航、标题基线与内容起点稳定；筛选、表单、表格形成连续工作面，卡片只表达真实实体或工具边界，不嵌套装饰卡片。
- 页面突出主工作区与主要操作。标题仅附必要日期/范围/状态，不重复解释性副标题、英文眉题或统计。低频操作可分组或进菜单，常用操作保持可见，不为主题差异增加业务步骤。
- 字体与资源离线可用；引入资源前核对授权、体积和回退，不引用个人电脑路径。

## Classic 基础参考

下表不强制覆盖其他主题；优先沿用已有 token，业务组件不散落一次性颜色。

| 用途 | 变量/尺寸 |
| --- | --- |
| 标题、正文、次要文字 | `--ink-950`、`--ink-800`、`--ink-500` / `--ink-600` |
| 画布、面板 | `--admin-canvas`、`--admin-surface` |
| 主操作、选中、焦点 | `--admin-blue`、`--admin-blue-soft`、`--focus-ring` |
| 成功、待处理、异常 | `--green-700`、`--amber-700`、`--red-700`，同时用文字表达 |
| 页面标题、模块标题、正文 | 28–32px、17–18px、13–14px |
| 表头、标签、辅助说明 | 12px；所有主题可见文字不低于 12px |
| 字体 | 正文 `--font-sans`，时间/编号/数字矩阵可用 `--font-mono` |
| 页面/面板/字段间距 | 20–24px / 12–20px / 10–16px |
| 标准/小/图标按钮高度 | 40px / 34px / 36px |
| 普通表格行高、页面最大宽度 | 56px、1420px |
| 控件/面板/模态框圆角 | 4–6px / 7px / 7–8px |

普通边框、表头和筛选区优先中性灰，内容面板白底；蓝色只强调品牌、主操作、链接和选中状态。阴影轻量，不整块悬浮或大面积发光。

## 控件与状态

- 按钮沿用 `primary`、`secondary`、`text`、`danger` / `danger-text` 层级；同组高度、图标、焦点及按压反馈一致，文案写明确动作。纯图标按钮有 `title` 与 `aria-label`。
- 表单遵循 AGENTS.md 的标签、校验和失败保留规则；加载、空数据、失败与只读状态可区分，失败可重试。只读关闭不显示保存。
- 查询提示优先级为加载中、请求失败、未应用筛选、正常说明；失败不能被输入草稿提示遮盖。`shared/ui/QueryStatus.vue` 仅负责该提示及状态播报，不持有筛选、请求、重试、导出或缓存。结果摘要使用最近成功查询的条件，失败重试使用页面捕获的原请求；各页面保留自己的摘要内容、样式和主题布局，培训两级查询与成员筛选不强行套用。
- 成功查询为零条时仍保留结果范围和计数，不能把首次加载或失败当成成功空结果。空状态文案限定于当前条件；“调整筛选”等入口保留输入，不自动清除条件或发起请求。
- 长表固定表头，矩阵可固定关键列及合计列；操作列宽度稳定，长内容可读，热力底色克制并有图例。悬浮不移动整行。
- 布局不随文字、加载或错误反馈跳动；窄屏标题和操作可换行，主要动作不挤出视口。
- 弹窗保留焦点陷阱、Esc、关闭回焦及滚动锁；动效绑定真实状态，不伪造保存成功或等待动画才提交，视觉取消不代表撤销服务器写入。

## 后台命令工作区

首页保留各主题的任务工作面与稳定输入区，不做黑色终端、独立悬浮控制台或多层卡片。行为、键盘、补全及无障碍语义统一由命令契约定义。

- 输入区位于首页标题后的主工作区，沿用各主题布局；采用紧凑输入与独立状态行，桌面输入高 56px，窄屏不低于 48px，字号 18–20px（窄屏 16px）。首页快捷操作最多三项，保留可见边界和悬停反馈。
- `/` 用等宽字体与品牌色；已输入文本高对比，唯一尾字补全使用约 35%–45% 的视觉强度，不能像已输入文本。右侧只留执行按钮，命令不完整时禁用但不隐藏。
- 建议面板与输入框等宽，优先在上方空间足够时上展，否则选择可用空间更大的一侧；总高不超过 320px 和视口可用空间，缩放时换算局部尺寸。标题固定，仅建议列表滚动，阻止滚轮带动页面；行高至少 56px，换行可增高。键盘活动项仅滚动列表，不移动整页。显示当前参数、类型与直接结果，不重复整句或堆彩色标签。
- 命令路径在建议面板顶部显示真实语法层级；已确认、当前、未填节点分别用正文、品牌强调、次要文字。分隔用箭头，不做胶囊；路径可横向滚动。移动光标同步当前节点，不重播整条动画。
- 键盘活动项用浅蓝背景与 2px 指示线，鼠标悬停用中性灰，两者独立；普通搜索不展示命令路径。
- 等待参数强调当前节点；命令完整显示摘要并启用执行；错误标出参数并给原因；执行中锁定重复操作，面板保持稳定；完成用 1.5–2.5 秒 Toast，不增加长期成功卡片。
- 层级切换 180–340ms 淡入、位移不超过 10px，不逐行飞入；输入聚焦只用可见焦点与轻量阴影，整体位移不超过 1px。

## 响应式与动效

- Classic 参考断点：1180px 以下筛选两列、页头换行，900px 以下导航抽屉，680px 以下筛选/表单单列。其他主题按自身结构适配，不强套导航形式。
- 表格和矩阵在自身容器内滚动，页面不整体横向溢出；680px 以下命令建议隐藏次要结果说明，保留参数、类型和活动状态。
- 受影响布局验收至少含 1440、1180、900、680、520px，Windows 125%/150% 与浏览器 200% 缩放；浏览器与 Electron 的适用范围按 AGENTS.md。
- 页面切换轻微淡入、位移不超过 4px，菜单/弹窗 140–220ms，按钮反馈不超过 1px；禁止表格逐行飞入、面板整体上浮和循环装饰动画。
- `prefers-reduced-motion` 下取消位移、缩放并缩短非必要过渡，保留立即可见的状态与焦点；不绕过未保存离开约束。

## 隐私与样式归属

- 后台 `AdminLayout.vue` 只承载路由出口；页面通过 `RefinedWorkspaceShell.vue`（成员页经 `MemberWorkspaceShell.vue` 转发）提供导航、主内容焦点和主题结构。新页面沿用该入口，不在路由父布局再叠一层导航、计时器或弹窗监听。权限继续由路由守卫和后端负责。
- `.mw-*` 的共享导航、主题变量、基础控件、表格及弹窗规则位于 `styles/workspace.css`；成员筛选、选择控件、记录及移动列表规则位于 `features/members/presentation.css`，仅成员页导入。共享控件沿用现有类名，不因历史 `mw-` 前缀将其归入成员业务。
- 各后台页面先导入 `styles/workspace.css`，再导入各自 feature 样式；成员页也遵循此顺序。这里保留显式页面入口，以保持相对其他展示样式的加载顺序；不要同时在 Shell 内重复导入，或把业务专属覆盖重新堆入共享文件。移动规则须保留选择器和媒体条件，并对照三主题布局。

- 公开签到台仅显示学号后四位，不长期保留上一位成员身份；维修电话默认脱敏、按需临时展开。敏感操作用应用内确认。
- 命令建议和尾字补全不枚举真实姓名、完整学号、电话或维修编号；参数存储边界见命令契约。
- `frontend/src/styles/` 中：`tokens.css` 管语义变量，`components.css` 管基础控件，`admin-shell.css` 管导航布局，`admin-details.css` 管页面细节，`admin-interactions.css` 管菜单等交互，`admin-theme.css` 管 Classic 视觉。
- `today.css`、`schedule.css`、`command-center.css` 管对应工作区；其他主题在 `frontend/src/appearances/`，业务展示样式留对应 feature。修改先找归属，不靠文件末尾重复覆盖同一选择器。
