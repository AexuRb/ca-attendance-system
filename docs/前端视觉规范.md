## 控件与状态

- 按钮沿用 `primary`、`secondary`、`text`、`danger` / `danger-text` 层级；同组高度、图标、焦点及按压反馈一致，文案写明确动作。纯图标按钮有 `title` 与 `aria-label`。
- 表单遵循 AGENTS.md 的标签、校验和失败保留规则；加载、空数据、失败与只读状态可区分，失败可重试。只读关闭不显示保存。
- 查询提示优先级为加载中、请求失败、未应用筛选、正常说明；失败不能被输入草稿提示遮盖。`shared/ui/QueryStatus.vue` 仅负责该提示及状态播报，不持有筛选、请求、重试、导出或缓存。结果摘要使用最近成功查询的条件，失败重试使用页面捕获的原请求；各页面按已确认方案呈现自己的摘要内容，同一页面在各主题下共用布局，培训两级查询与成员筛选不强行套用。
- 成功查询为零条时仍保留结果范围和计数，不能把首次加载或失败当成成功空结果。空状态文案限定于当前条件；“调整筛选”等入口保留输入，不自动清除条件或发起请求。
- 长表固定表头，矩阵可固定关键列及合计列；操作列宽度稳定，长内容可读，热力底色克制并有图例。悬浮不移动整行。
- 布局不随文字、加载或错误反馈跳动；窄屏标题和操作可换行，主要动作不挤出视口。
- 弹窗保留焦点陷阱、Esc、关闭回焦及滚动锁；动效绑定真实状态，不伪造保存成功或等待动画才提交，视觉取消不代表撤销服务器写入。

## 后台命令工作区

首页三主题共用任务工作面与稳定输入区，不做黑色终端、独立悬浮控制台或多层卡片。行为、键盘、补全及无障碍语义统一由命令契约定义；具体页面安排仍须单独讨论并取得开始授权。

- 今日输入与常用功能采用上文已授权的对话操作入口布局；三主题位置与结构一致，输入字号 18px（窄屏 16px），常用入口保留边界和悬停反馈。其他复用页仍须逐页授权，不自动套用今日内容。
- `/` 用等宽字体与品牌色；已输入文本高对比，唯一尾字补全使用约 35%–45% 的视觉强度，不能像已输入文本。右侧只留执行按钮，命令不完整时禁用但不隐藏。
- 建议面板与输入框等宽，优先在上方空间足够时上展，否则选择可用空间更大的一侧；总高不超过 320px 和视口可用空间，缩放时换算局部尺寸。标题固定，仅建议列表滚动，阻止滚轮带动页面；行高至少 56px，换行可增高。键盘活动项仅滚动列表，不移动整页。显示当前参数、类型与直接结果，不重复整句或堆彩色标签。
- 命令路径在建议面板顶部显示真实语法层级；已确认、当前、未填节点分别用正文、品牌强调、次要文字。分隔用箭头，不做胶囊；路径可横向滚动。移动光标同步当前节点，不重播整条动画。
- 键盘活动项用主题选中背景与 2px 指示线，鼠标悬停用主题悬停背景，两者独立；Classic 分别使用浅蓝与中性灰。普通搜索不展示命令路径。
- 等待参数强调当前节点，完整命令启用发送；错误给出原因，查询中锁定重复发送，对话回复不等同业务成功。点击操作按钮导航后沿用简短 Toast，表单和危险操作保留原有确认。
- 层级切换 180–340ms 淡入、位移不超过 10px，不逐行飞入；输入聚焦只用可见焦点与轻量阴影，整体位移不超过 1px。

## 隐私与样式归属

- 后台 `AdminLayout.vue` 只承载路由出口；页面通过 `RefinedWorkspaceShell.vue`（成员页经 `MemberWorkspaceShell.vue` 转发）提供导航、主内容焦点和共用布局入口。整体布局阶段按用户确认方案调整该入口，不为各主题建立独立骨架，不在路由父布局再叠一层导航、计时器或弹窗监听。权限继续由路由守卫和后端负责。
- `.mw-*` 的共享导航、主题变量、基础控件、表格及弹窗规则位于 `styles/workspace.css`；成员筛选、选择控件、记录及移动列表规则位于 `features/members/presentation.css`，仅成员页导入。共享控件沿用现有类名，不因历史 `mw-` 前缀将其归入成员业务。
- 各后台页面先导入 `styles/workspace.css`，再导入各自 feature 样式；成员页也遵循此顺序。这里保留显式页面入口，以保持相对其他展示样式的加载顺序；不要同时在 Shell 内重复导入，或把业务专属覆盖重新堆入共享文件。移动规则由各主题共用，主题覆盖仅处理配色、字体、动效和背景，不覆盖布局。

- 公开签到台仅显示学号后四位，不长期保留上一位成员身份；维修电话默认脱敏、按需临时展开。敏感操作用应用内确认。
- 命令建议和尾字补全不枚举真实姓名、完整学号、电话或维修编号；参数存储边界见命令契约。
- `frontend/src/styles/` 中：`tokens.css` 管语义变量，`components.css` 管基础控件，`admin-shell.css` 管导航布局，`admin-details.css` 管页面细节，`admin-interactions.css` 管菜单等交互，`admin-theme.css` 管 Classic 视觉。
- `today.css`、`schedule.css`、`command-center.css` 管对应工作区；其他主题在 `frontend/src/appearances/`，业务展示样式留对应 feature。修改先找归属，不靠文件末尾重复覆盖同一选择器。
