# 前端视觉规范

本规范用于计算机协会本地管理系统的后台、登录页和签到台。界面应保持克制、清晰、适合普通办公显示器长期使用。

## 设计原则

1. 业务信息优先，装饰不能争夺注意力。
2. 协会蓝用于品牌、主操作、链接和当前选中状态。
3. 普通页面使用中性灰白画布与白色工作面板。
4. 状态必须同时使用文字和颜色表达。
5. 动效用于说明状态变化，不让大面积内容反复移动。

## 色彩

| 用途 | 变量 | 使用范围 |
| --- | --- | --- |
| 主文字 | `--ink-950` | 标题、关键数值 |
| 正文 | `--ink-800` | 表格、表单、普通内容 |
| 次要文字 | `--ink-500` / `--ink-600` | 时间、说明、元数据 |
| 画布 | `--admin-canvas` | 后台内容区 |
| 面板 | `--admin-surface` | 表格、表单和内容面板 |
| 品牌蓝 | `--admin-blue` | 主按钮、选中态、链接 |
| 成功 | `--green-700` | 已完成、有效、启用 |
| 待处理 | `--amber-700` | 待审核、处理较久 |
| 异常 | `--red-700` | 未签退、失败、危险操作 |

不要用蓝色表达所有信息。普通边框、表头和筛选区应优先使用中性灰色。

## 字体层级

| 内容 | 字号 |
| --- | --- |
| 页面标题 | 28-32px |
| 模块标题 | 16px |
| 正文和表格数据 | 13px |
| 表格表头 | 11-12px |
| 表单标签 | 12px |
| 状态标签 | 11px |
| 辅助说明 | 11-12px |

中文正文使用 `--font-sans`，时间、编号和数字矩阵可使用 `--font-mono`。不得用 9px 字号制造精致感。

## 间距和尺寸

- 页面内容间距：20-24px。
- 面板内部间距：12-20px。
- 表单字段间距：10-16px。
- 标准按钮高度：40px。
- 小按钮高度：34px。
- 图标按钮：36px。
- 表格普通行高：56px。
- 页面最大内容宽度：1420px。

固定格式界面必须使用稳定尺寸或网格约束，避免文字和状态变化导致布局跳动。

## 圆角和阴影

- 按钮、输入框和小菜单：4-6px。
- 面板和表格：7px。
- 模态框：7-8px。
- 常规业务面板只使用轻微阴影。
- 不使用整块面板悬浮或大面积发光效果。
- 不嵌套装饰性卡片。

## 按钮层级

- `primary`：页面唯一或最重要的提交操作。
- `secondary`：导入、筛选、刷新、取消等次要操作。
- `text`：协议预览、清除筛选等低权重操作。
- `danger` / `danger-text`：删除、清空等不可逆操作。
- 多个低频行操作应放入“更多”菜单。

纯图标按钮必须有 `title` 和 `aria-label`。存在常见图标时不使用文字胶囊代替。

## 状态表达

- 成功：绿色标签或边线，同时显示“有效”“完成”等文字。
- 待处理：琥珀色，并显示待处理数量或原因。
- 异常：红色，并提供下一步操作。
- 普通信息：中性灰。
- 无数据：显示明确空状态，不留下空白面板。

## 表格和矩阵

- 表头使用中性灰底，正文保持白底。
- 长表格固定表头。
- 横向矩阵可固定关键左列和右侧合计列。
- 行悬浮只改变浅背景，不让整行位移。
- 数值热力底色必须克制，并提供图例。
- 操作列保持稳定宽度。

## 页面标题

后台页面使用统一结构：

```text
页面标题
一行用途说明

[次要操作] [主要操作]
```

“今日”页面可以使用日期替代用途说明。后台页面不重复显示英文分类眉题。

## 动效

- 页面切换：轻微淡入和不超过 4px 的位移。
- 菜单和弹窗：短距离展开，时长 140-220ms。
- 按钮：允许 1px 的按压或悬浮反馈。
- 禁止表格逐行飞入、面板整体上浮和循环装饰动画。
- 所有动效必须支持 `prefers-reduced-motion`。

## 响应式

- 1180px 以下：筛选区使用两列网格，页头操作允许换行。
- 760px 以下：后台导航切换为抽屉。
- 680px 以下：筛选区和表单改为单列。
- 数据表格和排班矩阵在自身容器内滚动，不让页面整体产生横向滚动。
- 验收尺寸至少包含 1440、1180、900 和 680px，并检查 Windows 125% 缩放。

## 隐私

- 公共签到台只显示学号后四位。
- 维修联系电话默认脱敏，按需临时展开。
- 不在页面上长期保留上一位签到成员的身份信息。
- 敏感操作必须使用应用内确认弹窗。

## CSS 文件职责

- `tokens.css`：全局色彩、字体、间距和基础变量。
- `components.css`：通用按钮、表单、表格和面板结构。
- `admin-shell.css`：后台主导航、二级导航和内容区布局。
- `admin-details.css`：具体业务页面的结构与细节。
- `admin-interactions.css`：菜单、筛选标签等交互组件。
- `admin-theme.css`：唯一的后台最终视觉层，不再重复定义两套主题。
- `today.css`、`schedule.css`：对应复杂页面的专属布局。

新增样式前应先确认归属文件，避免使用文件末尾覆盖前面同一选择器的方式修复问题。
