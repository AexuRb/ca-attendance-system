## 3. 本轮修复

- 成员和培训 Excel 导入从“跳过错误行并提交其他行”改为“任一错误整批回滚”。
- 固定排班手动编辑补齐启用星期校验，星期设置补齐固定排班引用保护和事务保护。
- 公开排班查询为旧数据增加停用星期过滤。
- 修复历史 `PUBLIC_DEVICE` 协议在维修页被标记为“维修协议”的显示错误。
- 自定义导出的数据选择变更后会清除过期预览，避免预览与实际文件不一致。
- 培训和维修页面改为服务端分页工作区，避免历史数据持续增长时整页一次渲染。
- 培训和维修编辑器加入独立操作锁、未保存离开确认、行内错误和首个错误聚焦；协议预览阻止旧响应覆盖新目标。
- 维修历史在 1100 像素以下改为紧凑档案卡，消除中窄屏表格溢出和字段碰撞。
- 修复维修确认项、负责人和完成时间边界，培训导入改为事务内原子 upsert，并统一枚举、关键词、年级和下载文件名校验。
- 统一前端最新请求、独立操作锁、失败保留与重试状态，补齐日期和上传文件的请求前校验及改密成功反馈。
- 统一 listbox、tablist、弹窗、菜单和 Toast 的键盘及焦点行为，收窄签到台动态播报范围，并让后台服务状态使用真实健康检查。
- 拆分前端生产与测试 TypeScript 配置，生产代码启用更严格的未检查下标和未使用项规则；设计 token 统一语义色与全局浮层层级，清理确认无调用的旧样式。

## 4. 验证结果

任务 12 已完成。后端完整测试、前端测试、类型检查、生产构建、脚本测试、四档视口检查和大数据功能验收均已按隔离环境完成；测试数量不在文档中固定记录，以 CI 运行时生成的 Surefire、Vitest、Node 和 unittest 汇总为准。

`ui-core-workflows-test.py` 是夹具驱动的前端渲染与工作流冒烟，API 响应在浏览器内拦截，不能证明后端权限。真实后端的角色页面与接口权限回归使用 `ui-role-regression.py`，属于发布前手动门禁，不能用前者替代。

完整 API 冒烟脚本已移除个人资料更新请求中的只读年级字段。本轮未主动重新打包 JAR，发布前仍需使用当前构建结果复跑完整冒烟。

## 5. 已知边界与风险

- Excel 导出统一最多 50,000 行，超过时要求缩小筛选范围。
- 排班 Excel 导入最多 1,000 行；成员和培训 Excel 导入最多 3,000 行；这些是导入上限，不是导出上限。
- 安装包目前没有代码签名，Windows 可能显示安全提示；SQLite 主库和备份未加密，发布和交接时必须限制文件系统访问并保护备份文件。
