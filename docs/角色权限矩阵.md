# 角色权限矩阵

## 1. 使用原则

- 本文档描述当前系统的权限基线，适用于 Windows 桌面端、本机 Web 端和受限远程管理端。
- 前端路由、导航和按钮权限用于减少误操作；后端服务权限才是最终安全边界。
- 普通成员、部长、会长和管理员的账号均可在主机本地登录。
- 3.6.0起远程入口允许四种角色登录；远程部长的业务只读，成员只使用本人资料与记录。会长、管理员沿用原权限，远程不提供签到台、首次初始化或桌面控制能力。下方本机基线结合第5节远程限制使用。
- 账号停用后，已有登录令牌也必须失效。

## 5. 特殊边界

### 5.1 会长与管理员账号

- 会长不能新增管理员、把账号调整为管理员、修改管理员资料、停用管理员或重置管理员密码。
- 成员 Excel 导入命中管理员学号时，会长操作必须跳过该行并返回明确提示；其余行完整校验通过后整批写入，任一非跳过行错误均不写入。
- 管理员调整或停用其他管理员前，系统必须确认仍有至少一个启用的管理员账号。

### 5.2 部长的值班权限

- 部长签到和签退自动通过。
- 部长可处理本周普通成员和部长的值班记录。
- 部长不能处理会长、管理员或自己的待审核记录。
- 部长不能手动新增记录，也不能进入成员、排班、培训、数据中心或系统设置页面；签到判定读取当前星期和时段不授予修改权限。

### 5.3 远程入口

- 远程登录允许启用的成员、部长、会长和管理员；初始密码强制修改、登录限流、审计与停用失效规则保留。
- 远程成员只可读取本人账号、值班、培训记录和鸣谢，修改本人资料、密码及退出；本人记录由当前登录ID限定，不接受其他成员ID作为授权依据。
- 远程部长保留今日概览、全部值班记录、统计/标准统计导出、整周排班、维修列表/详情及协议预览打印；无审核页面、审核队列或审核API权限，不能补录/修改/删除值班记录，不能创建/修改/删除维修或变更状态，也不能使用编辑候选名单接口。
- 成员及部长远程API采用明确的方法/路径允许集合；除本人资料和密码、退出外不开放写请求，未来新增接口默认拒绝。允许标准统计导出和维修协议读取，维修Excel导出、数据中心、备份、名册管理等不因本次开放而授权。
- 本机部长原管理能力不变，远程会长和管理员仍受各自原业务权限约束；同一个本机令牌转到远程请求也按远程限制处理。
- 登录说明统一“使用学号和密码登录”；远程部长隐藏审核导航/待办/命令、值班操作列与维修写入口，保留自然只读布局及个人账号维护。
- 远程请求每次都根据数据库中的当前角色和状态重新校验，不能依赖登录时的旧角色。
- 远程端口拒绝公开签到接口、初始化操作和桌面控制接口。
- 远程读取公开排班数据前仍须登录且具有排班查看范围；远程成员不开放排班。成员的REMOTE_ADMIN仅表示远程登录资格，不代表管理权限。

调整角色权限时，应同步更新本文档、前端权限测试和后端接口测试。只修改页面按钮或只修改后端枚举都不算完成。

统计来源追溯：具有统计查看权限的部长、会长和管理员可以查看指定成员、指定日期范围的有效值班日汇总及培训日期、标题、该成员计入时长。此接口不返回培训参与名单、备注或联系方式，不授予培训管理权限。
