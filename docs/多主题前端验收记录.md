# 多主题前端验收记录

## 范围与环境

日期：2026-09-04。本轮对应 `plan.md` 的阶段 6，仅验收前端，不是发布或桌面成品验收。Classic 保持既有视觉；Editorial、Spatial 分别沿用已确认的 Claude、Apple 参考。三套界面共用业务组件、接口和权限。

使用本地 Vite 与真实 Chromium，所有 API 均由 Playwright 返回虚构内存数据，没有读取或修改正式数据库。主题选择保存、审核、删除、导出等模拟响应不等于真实数据库写入或文件生成验证。

## 覆盖矩阵

| 检查项 | 实际覆盖 |
| --- | --- |
| 后台直达页面 | 3 套主题 × 4 种角色的全部允许路由 × 5 种视口，共 450 次页面检查；管理员覆盖 12 个后台页面 |
| 权限显示 | 成员、部长、会长、管理员允许路由；前三种角色各一个代表性禁止路由；不替代后端授权测试 |
| 视口 | 1440×900、1080×720、1152×720、960×600、390×844；侧栏默认展开，窄屏遵循现有折叠逻辑 |
| 缩放边界 | 1152×720 和 960×600 模拟 1440×900 下 125%/150% 缩放的有效 CSS 空间，不是操作系统 DPI 或 Electron 原生缩放实测 |
| 公共页面 | 三主题签到台、登录、初始化覆盖五种视口；强制修改密码覆盖四角色与五种视口 |
| 主题切换 | Classic → Editorial → Spatial → Classic；失败保留原主题、重试成功、刷新恢复、回到 Classic 后基础计算样式一致 |
| 故障回退 | 未知主题、配置读取失败、新主题入口资源加载失败，回退 Classic 且登录页可见；资源中断测试针对 Vite 模块路径 |
| 会话与入口 | 会话失效清除客户端登录状态；模拟远程入口转向登录且不显示签到台入口 |
| 长内容与浮层 | 三主题 40 条长姓名/学院的成员列表和新增弹窗；复用维修、培训、统计、数据与备份、日志专项的填充数据、分页与浮层检查 |
| 反馈与键盘 | 复用双主题加载、失败重试、空态、成功反馈、确认取消/执行、Tab 循环、Escape 焦点恢复和 reduced-motion 测试 |

`multi-appearance-acceptance.spec.ts` 对后台路由检查脚本错误、控制台错误/警告及整页横向溢出。直达链接使用独立文档导航，避免上一页异步 URL 同步影响用例；另用真实侧栏链接连续往返数据与设置页，不以页面重载代替站内导航验证。

## 发现与修复

| 已复现问题 | 处理 |
| --- | --- |
| Editorial 个人资料在 1080px 窗口溢出 155px | 提取 `editorial/profile-page.css`，按内容容器宽度切换单列；筛选栏独立换行、查询文字不拆行，窄屏三项时长等宽排列 |
| Editorial 首页在 1152px 窗口溢出 92px | `editorial/today.css` 双栏断点改为内容容器查询，计入侧栏占用 |
| Spatial 统计在 1080px 窗口溢出 35px | `spatial/stats-page.css` 的筛选与指标断点改为容器查询 |
| 两套新主题培训筛选在 960px 窗口溢出，Editorial 70px、Spatial 45px | 各自 `training-page.css` 按内容宽度转为双列/单列，详情区域同步适配 |
| 设置数据未加载完成时，未操作也出现“放弃未保存修改” | `useSettingsWorkspace.ts` 只有取得对应基线后才比较业务表单差异，外观草稿仍独立保护；延迟加载用例修复前失败、修复后通过，另验证真正修改后的取消和放弃 |

这些样式仍限定在相应主题内，主题 CSS 单文件均未超过 500 行。没有修改角色、业务计算、后端接口或数据库结构。子代理只读核对了角色路由与权限文档，主代理复核并补充密码页和远程入口显示测试。

## 边界与后续

本轮不包含真实后端并发/权限校验、真实数据导入导出、备份恢复、离线安装、Electron 协议预览、系统 DPI 和安装包资源回退。容器查询已在本轮 Chromium 中通过，但旧安装版 Electron 未验证。需要用户明确要求打包或发布后，再按发布检查表执行这些成品检查。

历史 `后台页面视觉验收.md` 保留原有阶段数据，不作为当前测试数量或新主题约束。当前进度以 `DEV_STATE.md` 为准。

2026-09-04 用户授权本地打包后补充了真实成品检查，见 [桌面端稳定性测试记录](桌面端稳定性测试记录.md) 第 7 节。三主题维修/培训写入、协议预览和 Excel 下载已验证，但内部容器断言复现 Classic 个人资料查询按钮在 125% 缩放裁切、Spatial 个人资料时长项在 150% 缩放裁切；两项尚未修复。本页先前的 mock/整页宽度验收结果不覆盖这些内部裁切问题，当前不能认定桌面视觉验收全部通过。
