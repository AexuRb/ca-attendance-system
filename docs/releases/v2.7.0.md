# v2.7.0 - 培训与维修工作区升级

本版本集中优化培训和维修两类高数据量业务，并补齐桌面窗口缩放与隔离数据验收。

## 主要更新

- 培训场次与参与名单改为服务端分页，工作位置可通过 URL 恢复；单场数千人时仍只渲染当前页。
- 培训页面重做为场次列表、场次详情和参与名单工作区，窄屏使用场次切换与详情抽屉。
- 维修页面改为状态标签、进行中工作区和历史档案，避免已完成记录长期累积导致页面过长。
- 维修详情改为抽屉浏览，联系电话默认脱敏；表单加入分步填写、行内错误、未保存提醒和独立操作锁。
- 完善培训、维修的筛选、分页、导入导出和角色权限回归测试。
- 桌面端新增窗口缩放烟测，并在 1,080 x 720 与 1,440 x 900 下验证无横向溢出。

## 下载说明

- `CA-Attendance-System-Setup-2.7.0.exe`：Windows x64 安装版。
- `CA-Attendance-System-Portable-2.7.0.zip`：Windows x64 便携版，解压后运行根目录中的启动脚本。
- `SHA256SUMS.txt`：两个发布包的 SHA-256 校验值。

## 升级说明

- 本版本没有新增数据库迁移，现有 SQLite 数据可以直接沿用。
- 更新前建议在“系统 > 数据”中创建完整备份。
- 安装版更新时请保留 `C:\CAAttendance\data`、`backups`、`exports` 和 `logs`。
- 便携版迁移时请整体保留上述四个数据目录，不要只复制程序目录。
- 安装包没有代码签名证书，Windows 可能显示安全提醒；请仅从本仓库 Release 下载，并核对 `SHA256SUMS.txt`。
