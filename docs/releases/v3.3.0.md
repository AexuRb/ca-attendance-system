# v3.3.0 — 三套独立工作空间与交互升级

2026-09-15。

## 本次更新

- Classic专业工作台、Editorial温暖编辑式、Spatial轻盈空间式分别采用独立导航与主内容布局，覆盖后台及登录、初始化、密码设置、签到台。
- 精修按钮、图标操作、字体、表单、系统设置与跨页动效，放大签到录入区域；保留键盘与减少动态效果支持。
- 修复公共页进入后台空白、导航焦点丢失、路由资源失败无提示、维修初始化抢占后续导航、签到旧响应覆盖后续输入。
- 成员导入完整校验后整批写入，支持学号、姓名、手机号、学院、年级、QQ；新增HTTP边界与失败回滚检查。重复学号返回可理解的业务错误。
- 更新桌面构建链兼容修复依赖，完整npm审计未发现已报告漏洞。

前端测试、类型检查、构建，后端测试与依赖上界检查，桌面及脚本测试/语法检查通过。测试数量来自各运行报告，不作为固定发布指标。
