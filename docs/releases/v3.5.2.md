# v3.5.2 - 鸣谢权限与值班记录体验修复

## 本版变化

- 所有已登录角色都能在个人资料查看鸣谢。仅管理员可连续点击标题5次进入编辑页；其他角色直接访问编辑路由或保存接口仍会被拒绝。固定感谢语、首位贡献者及保存冲突保护保持。
- 值班记录去掉每行常驻的权限说明，桌面表格和窄屏卡片继续显示置灰按钮，悬停显示具体原因，无障碍名称也保留原因。部长不能修改会长/管理员和非本周记录的规则保持。
- 修复构建依赖链中危告警：精确调整下载代理依赖，移除sprintf-js/roarr，补充下载行为测试；HTTPS兼容补丁受版本和源码SHA-256约束，保留CA、servername及证书校验。Electron固定版本保持，构建依赖不随成品分发。
- 补齐历史版本分支，并明确独立分支开发、验证后合并main、打标签发布及保留版本分支的流程。

## 升级与回滚

无新增数据库迁移，继续使用原数据库。升级前从托盘完全退出程序，备份并保留data与backups；安装版保留数据，便携版仅替换app目录。回滚先保留当前数据，再使用上一版本程序及必要时的升级前备份，不手工修改SQLite。

维修事务导出、培训记录导出与今日概览输入框/命令功能的改版继续保留待办；需先确认需求与布局，本版不扩展这些功能。

## 验证与发行边界

本轮干净安装实际执行桌面安装钩子，前端与桌面完整依赖审计均无告警。前端完整测试、应用及测试类型检查、构建，后端鸣谢服务/API与角色权限定向测试、Maven依赖上界检查，桌面完整测试及JavaScript语法检查、非数据库脚本用例和PowerShell语法检查均通过。完整后端及脚本测试在发布提交推送后交由GitHub CI执行，正式发布以CI通过为前提，最终运行链接随Release记录提供。

安装版与便携版由正式构建脚本生成，版本和SHA-256一致，便携程序逐文件与成品一致，JAR静态资源与前端构建一致；数据、备份、导出和日志目录为空，无真实数据库或凭据。成品ASAR不含sprintf-js、roarr、global-agent、electron-builder或构建兼容补丁。成品Electron复用项目原data/attendance.db，启动健康、两种窗口尺寸无根横向溢出、托盘隐藏/恢复及完全退出通过，8080与8081仅绑定127.0.0.1，测试进程已退出。

本轮受影响页面已做原库浏览器检查；其他角色的入口、编辑跳转及API边界由自动化测试验证，部长提示展示另用临时前端角色模拟核对，未改真实账号角色。未新建或复制业务数据库，未重演会创建临时数据库的本地完整集成/脚本用例；完整后端及脚本测试由托管CI执行。未重演隔离API/真实多角色UI、性能基线、全部主题/页面、桌面异常退出/目录迁移及安装器覆盖升级，不据此宣称完整手动验收。此前HTTPS下载直连、代理、NO_PROXY、CA校验与兼容补丁哈希拒绝/幂等检查见DEV_STATE.md；本轮重新运行干净安装及下载代理自动测试。

安装包未代码签名，Windows可能提示未知发布者；SQLite主库及备份未加密。未对已安装程序执行安装/卸载或覆盖升级。
