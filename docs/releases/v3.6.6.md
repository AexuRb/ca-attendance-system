# v3.6.6 后台动效与交互优化

## 本版变化

- 后台切页时，两个工作区按左侧菜单顺序连续上下滑动。排班、个人资料、维修事务、数据统计与数据中心的选项增加滑动底板。
- 签到台的选择、确认与成功反馈采用分层动效。今日概览的常用功能及在场名单分步出现，自动刷新时提示变化的数字。
- 居中弹窗分层展开，侧边抽屉沿边缘滑动，关闭后恢复键盘焦点。成功通知显示勾号，鼠标悬停或键盘聚焦时暂停自动关闭。尊重系统的「减少动态效果」设置。
- 成员保存错误独立显示在表单内，填写内容可直接重试。修复忙碌弹窗焦点及通知重复暂停的倒计时问题。

## 升级与回滚

本版沿用 SQLite V12 和备份格式 5。从 3.6.5 升级前，请从托盘完全退出并备份 `data` 与 `backups`。便携版升级时只替换 `app` 目录。回退时先备份当前数据，再用上一版程序启动。

安装包未代码签名，Windows 可能提示未知发布者。SQLite 主库和备份未加密。

## 本地验收

- 干净安装依赖后，前端测试、类型检查与构建、桌面测试、后端定向测试与依赖上界检查均通过。生产依赖审计无告警，完整审计中的中危项目来自构建依赖。
- 使用正式打包脚本生成 Windows 安装版和便携版，核对内部版本、静态资源、空数据目录和 SHA-256。用项目数据库检查成品启动、窗口缩放、托盘隐藏与恢复以及退出，业务表校验值一致。8080 浏览器验证使用模拟数据。
- 本地验收未覆盖空库与隔离备份恢复、真实后端角色全量回归、性能基线、Windows 11 实测和安装器覆盖升级。

## 发行文件

- `CA-Attendance-System-Setup-3.6.6.exe` 为 Windows x64 安装版。
- `CA-Attendance-System-Portable-3.6.6.zip` 为便携版，包含程序、空数据目录和启动说明。
- `SHA256SUMS.txt` 用于校验两个发行文件。
