# v3.0.0 - 离线管理平台质量升级

本版本完成一次覆盖数据安全、权限边界、前后端可靠性、桌面运行和大数据性能的系统性升级，并将发布流程纳入可重复验证。

本页对应 2026-08-24 重新生成的同版本替换构建；旧的 `v3.0.0` 安装包和便携包已由修复后的发行文件替换。

## 主要更新

- 加固 SQLite 备份与恢复，限制压缩包容量和条目数量，使用一致性快照、临时文件和原子发布保护业务数据。
- 统一签到、成员、培训、排班、维修及日志写操作的事务与审计边界，失败时不再留下部分更新。
- 收紧本机与远程入口权限，远程只允许会长和管理员登录，公开签到台继续仅在主机本地提供。
- 成员、签到、培训、维修和日志列表统一分页，Excel 导出设置 50,000 行上限，导入按业务设置明确容量限制。
- 培训和维修页面改为适合长期数据积累的分页工作区，并完善筛选、抽屉、表单校验、未保存提醒和窄屏布局。
- 签到台、登录页和后台统一淡蓝色设计语言，补齐焦点管理、键盘操作、动态状态和浏览器缩放适配。
- Electron 增强托盘、单实例、端口冲突、窗口恢复、凭据保存和异常退出诊断，继续内置 Temurin JRE 21。
- 修复新安装空数据库无法进入首个管理员初始化流程，以及 Electron 视觉缩放参数错误导致窗口只显示淡蓝底色的问题。
- 初始化页与登录页统一淡蓝色认证布局、字段标签、密码显隐和焦点反馈，Windows 打包脚本兼容 UTF-8 中文资源路径。
- CI 增加后端、前端、桌面端和脚本测试，校验静态资源漂移、依赖边界、生产依赖安全和格式质量。

## 下载说明

- `CA-Attendance-System-Setup-3.0.0.exe`：Windows 10/11 x64 安装版。
- `CA-Attendance-System-Portable-3.0.0.zip`：Windows x64 便携版，解压后运行根目录中的启动脚本。
- `SHA256SUMS.txt`：发行文件的 SHA-256 校验值。

## 升级说明

- 启动时会自动执行所需 SQLite 迁移，不需要手工执行 SQL；更新前仍建议在“系统 > 数据”中创建完整备份。
- 安装版更新时只替换 `C:\CAAttendance\app`，保留同级 `data`、`backups`、`exports` 和 `logs`。
- 便携版迁移时应整体保留上述数据目录，不要只复制程序目录。
- 本版本移除了经确认无产品调用的旧接口；正常桌面使用不受影响。

## 已知风险

- 安装包没有代码签名证书，Windows 可能显示未知发布者或信誉提示。
- SQLite 主数据库和备份文件未加密，应限制无关人员访问安装根目录并妥善保管迁移副本。
- 请仅从本仓库正式 Release 下载，并使用 `SHA256SUMS.txt` 校验文件完整性。

## 验证说明

本版本在发布前执行后端、前端、桌面端和脚本自动化测试，完成类型检查、生产构建、依赖审计、隔离 API/UI 冒烟、角色权限回归、性能基线和真实桌面进程稳定性验证。具体测试数量以对应 GitHub Actions 运行结果为准。
