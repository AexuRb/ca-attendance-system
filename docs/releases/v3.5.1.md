# v3.5.1 - 导入模板与值班记录导出

## 本版变化

- 导入模板由后端统一生成，成员年级随运行年份、排班随当前系统配置、培训随所选场次生成；整理说明与虚构示例，文本学号保持完整。升级后请重新下载模板。
- 值班记录提供周、月、学期、自定义四个入口。月与学期按周分组，学期选择两个日期；按当前系统值班日筛选日期及有记录成员，排除非值班日记录，只汇总有效值班时长，不混入培训。Excel包含周小计、合计、文本学号及冻结表头/身份列；页面预览最多50人，导出保留全部符合条件的成员。
- 成员默认导出学号、姓名、学院、年级；部长排班默认星期、值班时段、姓名；其他字段仍可选，操作日志默认项保持。
- 数据中心移除统计汇总导出入口，数据统计页及查看统计命令保留；导出目录依次为成员、值班记录、部长排班、维修事务、培训记录、操作日志。
- 鸣谢入口移到个人资料右上角，后台标题改为“计算机协会值班管理系统”；签到台改善窗口放大适配，概览欢迎语使用普通展示并在首条消息后移除。

## 后续开发

维修事务与培训记录的导出优化，以及今日概览输入框/命令功能和对话形式的调整，已记入本地plan.md并同步DEV_STATE.md，留待下一次commit。先确定具体需求及布局，再开始对应开发；本版保留当前实现。

## 升级与回滚

本版无新增数据库迁移或运行依赖，使用原数据库。升级前从托盘完全退出，备份并保留data与backups；安装器保留数据，便携版只替换app目录。回滚先保留当前数据再更换为上一版程序，需要恢复数据时使用升级前备份，不手工修改SQLite。
