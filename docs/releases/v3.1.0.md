# v3.1.0 - 后台视觉与桌面体验升级

本版本集中优化后台日常使用体验，并修复桌面端升级后可能继续读取旧静态资源的问题。业务权限、离线运行方式和现有 SQLite 数据结构保持不变。

## 主要变化

- 统一后台页头、主次按钮、焦点和交互动效，减少重复说明文字。
- 系统设置使用微型日历选择值班星期，签到审核使用状态与操作合一的紧凑控件。
- 值班统计默认显示本周，固定周排班改为单日时间轴和完整名单布局。
- 维修事务改为高密度分页台账，培训记录改为月份时间带、场次概览和参与名单工作区。
- Electron 每次启动前清理渲染缓存，并为入口地址添加单次启动标识，避免新安装包继续调用旧前端接口。

## 下载说明

- `CA-Attendance-System-Setup-3.1.0.exe`：Windows 10/11 x64 安装版。
- `CA-Attendance-System-Portable-3.1.0.zip`：Windows x64 便携版，解压后运行根目录中的启动脚本。
- `SHA256SUMS.txt`：安装版和便携版的 SHA-256 校验值。

## 升级说明

- 本版本没有新增数据库迁移，现有 SQLite 数据可以直接沿用。
- 更新安装版时仅替换 `C:\CAAttendance\app`，保留同级 `data`、`backups`、`exports` 和 `logs`。
- 更新前建议在“系统 > 数据与维护”中创建完整备份。

## 已知风险

- 安装包没有代码签名证书，Windows 可能显示安全提醒。
- SQLite 主数据库与备份文件未加密，应限制主机、磁盘和备份目录的访问权限。

## 验证范围

发布前执行后端、前端、桌面端和脚本自动化测试，完成类型检查、生产构建、依赖审计、隔离 API/UI 冒烟、角色权限回归、性能基线和桌面真实进程稳定性验证；具体测试数量以对应 GitHub Actions 运行结果为准。
