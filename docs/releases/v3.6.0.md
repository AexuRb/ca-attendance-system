# v3.6.0 - 远程多角色登录与权限分离

## 本版变化

- 远程后台允许成员、部长、会长和管理员登录，说明统一为“使用学号和密码登录”。远程签到台、公开签到/签退、初始化和桌面控制继续关闭。
- 远程部长保留今日概览、值班记录查看、统计查看及标准统计导出、整周排班、维修列表/详情与协议预览和打印；不能审核、补录/修改/删除值班记录，也不能创建/修改/删除维修或变更状态。个人资料和密码仍可维护。
- 远程成员进入现有个人资料，可维护本人资料、修改密码、查看本人值班与培训记录及鸣谢；不开放其他成员数据或管理页面。本机部长及远程会长/管理员原权限保持。
- 后端根据请求连接器、数据库当前角色和请求方法/路径执行明确允许集合；直接调用接口、复用本机令牌或传入转发头也受远程限制。首次强制改密、账号停用后的会话失效、限流与审计保持。
- 前端同步导航、直接路由、概览待办/快捷操作、命令建议/树及别名解析，远程部长隐藏值班操作列和维修写入口，不读取编辑候选名单。
- 数据统计页补回标准统计导出入口，导出使用已加载成功的日期范围，日期草稿变化、加载失败或请求忙碌时禁用。
- 鸣谢弹窗恢复原来的居中标题、560px桌面宽、22px圆角、淡背景、水印和两列贡献名单，展示和编辑页预览一致；所有角色可查看，仅管理员可连续点击标题五次进入编辑。其他弹窗继续使用统一外观。

## 升级与回滚

无新增数据库迁移，继续使用原数据库。升级前从托盘完全退出，备份并保留data与backups；安装版保留数据，便携版只替换app目录。回滚先保留当前数据，再使用上一版程序及必要时的升级前备份，不手工修改SQLite。隧道仍只转发127.0.0.1:8081，8080保留本机使用。

主题字体引起的偶发窗口错位、维修事务/培训记录导出及今日概览后续改版继续留待下一轮。
