# v3.6.5 技能考核、签到台与今日概览

## 本版变化

- 新增拆机与重装系统两项考核，均可登记通过或未通过。会长和管理员在「成员名册」编辑普通成员的考核结果，本机部长可从「技能考核」登记当天从签到台签到的普通成员。部长、会长及管理员在任职期间两项固定通过。
- 签到台继续展示今日部长排班，并显示当前在场人员。待审核签到也计入，提交签退后移出。在场的当班部长计入人数，姓名在排班区展示。
- 今日概览的欢迎语、常用功能和今日信息在左侧，右侧按权限展示在场人员及两项考核结果。在场的当班部长也在右栏列名。今日信息展示待审核和进行中维修。原搜索框、指令与对话入口已移除。

## 升级与回滚

SQLite 将自动应用 V12 迁移。升级时，原有普通成员两项默认为未通过，部长、会长和管理员默认为通过。备份格式升至 5，记录两项考核结果。恢复缺少考核字段的旧备份时，系统按成员角色设定默认值。

升级前请从托盘完全退出并备份 `data` 与 `backups`。便携版升级时只替换 `app` 目录。若回退至 3.6.0，先保留现有数据，再使用升级前的备份。安装包未代码签名，Windows 可能提示未知发布者。SQLite 主库及备份未加密。
