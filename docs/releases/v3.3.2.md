# v3.3.2 — 请求恢复与数据一致性完善

2026-10-06。

## 更新内容

- 签到台请求超时后可恢复，同次确认重试沿用提交标识，避免重复签到和迟到响应覆盖输入。
- 页面资源失败提供重试与重新加载；离页取消保留地址和草稿，登录失效清理旧工作区。
- 改善工作区查询、分页和返回状态，修正培训汇总导出日期口径、统计筛选布局与有效记录次数说明。
- 修复备份恢复丢失文本登录时间小数秒，保留旧备份格式兼容、整批导入校验、恢复事务及审计。
- 更新 Vue 3.5.43、Electron 43.7.7 和相关依赖补丁；干净构建排除旧静态资源，本机 Electron 缓存须与锁定版本一致。

## 下载与升级

- `CA-Attendance-System-Setup-3.3.2.exe`：Windows x64 安装版。
- `CA-Attendance-System-Portable-3.3.2.zip`：含本地 Java 运行时的便携版。
- `SHA256SUMS.txt`：两个发行文件的 SHA-256 校验值。

升级前从托盘完全退出旧程序，备份 `data` 与 `backups`。本版没有新增数据库迁移；不要把新包的空数据目录覆盖到已有业务目录。恢复备份会撤销原登录，需重新登录。回滚先保留当前数据与备份，仅替换程序目录；数据不兼容时使用升级前备份，不手工改 SQLite。

## 依赖与已知边界

前端生产及完整审计无告警；桌面生产审计无告警，完整审计无高危或严重告警。桌面仍有中危 sprintf-js 拒绝服务告警及构建工具关联项：经 @electron/get → global-agent → roarr 的代理日志格式化链路使用，仅处于构建依赖，不包含在应用 ASAR；当前包上游没有可用修复版本。保留审计披露，不使用强制降级消除报告。
