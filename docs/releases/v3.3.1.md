# v3.3.1 — 三主题逐页精修

2026-09-25。

## 更新内容

- 签到台、登录、初始化、修改密码及全部后台页面完成逐页视觉与交互精修；保留 Classic、Editorial、Spatial 各自的布局和既有业务逻辑。
- 改善排班姓名呈现、成员批量操作稳定性、个人资料字段对齐、培训切换、数据中心页签位置及系统设置窄屏布局。

- 页面切换和状态反馈按主题采用不同过渡，并在减少动态效果设置下取消非必要位移。

## 下载与升级

- `CA-Attendance-System-Setup-3.3.1.exe`：Windows x64 安装版。
- `CA-Attendance-System-Portable-3.3.1.zip`：含本地 Java 运行时的便携版。
- `SHA256SUMS.txt`：两个发行文件的 SHA-256 校验值。

升级前从托盘完全退出旧程序并备份 `data` 与 `backups`。本版没有新增数据库迁移；已安装程序的数据目录不会随应用目录替换。
