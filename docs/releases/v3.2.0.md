# v3.2.0 - 全局多主题与后台命令台

## 本次更新

- 新增 Editorial 编辑式、Spatial 空间式界面，保留 Classic 经典界面。管理员可在系统设置中全局切换，后台、登录、初始化和签到台一同生效，重启后保留。
- 首页加入命令台，支持分级建议、参数补全与按角色显示的快捷入口。
- 重组有效时长、值班时间段及数据与备份页面，拆分业务状态与主题样式，三套界面继续使用同一套业务规则和权限。
- 登录次数限制只作用于远程入口，并增加远程整体失败计数；本机登录不受次数限制。
- 补充敏感写操作的影响行数检查、事务审计及提交后会话撤销。

## 下载

- `CA-Attendance-System-Setup-3.2.0.exe`：Windows 10/11 x64 安装版。
- `CA-Attendance-System-Portable-3.2.0.zip`：便携版，解压后运行根目录启动文件。
- `SHA256SUMS.txt`：安装版和便携版的 SHA-256 校验值。

## 升级

1. 从托盘完全退出程序，并保留完整备份。
2. 安装版更新 `app` 程序目录，保留同级 `data`、`backups`、`exports` 和 `logs`。
3. 首次启动自动执行 V11 迁移，为已有数据库增加默认全局外观配置，保留原业务数据。

需要回退时使用上一版程序和升级前备份，避免旧程序与迁移后的数据库版本不一致。

## 验证范围

沿用本轮已完成的前后端测试、类型检查、三主题浏览器验收及真实 Electron 成品检查。已验证空库初始化、三主题维修/培训创建与刷新留存、维修协议预览、Excel 下载、重启后数据和外观保留，以及托盘、单实例、回环绑定、异常退出、目录迁移和窗口尺寸恢复。发布封包按用户要求未重复这些本地测试；具体记录见仓库 `docs/桌面端稳定性测试记录.md`。

## 已知问题

- Classic 个人资料查询按钮在 125% 缩放下可能裁切；Spatial 个人资料时长项在 150% 下可能裁切。两项尚未修复，桌面视觉验收并非全部通过。
- 桌面依赖安装报告 1 中危、1 高危，完整审计服务查询超时，具体包和运行时影响待核清。
- 桌面实际操作在 Windows 10 上验证；未实测 Win11、安装向导、SmartScreen 或实际断网安装，未将这些项目标记为通过。
- 安装包没有代码签名证书，Windows 可能提示未知发布者。SQLite 主库和备份未加密，应妥善保管并校验下载文件。
