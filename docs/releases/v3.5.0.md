# v3.5.0 - 统一工作区与七套主题

## 本版变化

- 公共入口、签到台与后台采用已确认的统一框架，菜单与子菜单同时呈现；按实际窗口适配，取消固定1920×1080的依赖。
- 新增雾蓝、暖砂、晴空、松绿、雾紫、石墨、蔷薇七套主题。共用业务和布局，保留字体、圆角、材质及动效差异；初始化本机保持固定Spatial样式。
- 大小会徽共享位置和缩放过渡，统一文字、入口、浅主题与图标按钮；改善键盘焦点及减少动态偏好。
- 今日概览提供对话式查询、汇总与操作入口，右栏集中待审核、维修中及快捷功能；重整审核、记录、统计详情、成员和个人资料。
- 数据中心集中导入、模板下载及导出，补充统计汇总导出，命令台与数据中心入口衔接。备份与恢复仍独立保留。
- 排班默认整周概览，星期横排、时段纵排，只显示值班日；部长可只读查看，编辑、导入和人员候选仍由管理权限限制。
- 重做培训场次与参与名单，左栏每页8场，默认从当年1月1日起查询；精修维修、回收站、系统设置和操作日志。
- 维修协议使用单联正文并优化填写区；移除日志清空功能。个人资料修改密码改为独立页面。
- 管理员可维护鸣谢的附加贡献者；固定感谢语与发起人信息不可修改、删除或重排。

## 升级与回滚

本版没有新增数据库表结构迁移。七套主题ID沿用原全局设置项，新鸣谢使用现有设置存储；旧主题ID仍兼容。权限、事务及审计继续由后端执行。

升级前从托盘选择完全退出，备份并保留现有`data`与`backups`。安装器保留数据目录；便携版只替换`app`程序目录，不覆盖业务数据。旧版升级后可继续使用原数据库。

回滚前先保留当前数据，再替换为上一版本程序。若需要恢复数据，使用升级前备份，不手工修改SQLite。

## 验证与发行边界

本地后端测试、Maven依赖上界检查、前端受影响用例及类型检查、桌面单元测试、脚本测试与语法检查已通过；完整前端测试和提交静态资源一致性另由本版提交的GitHub CI把关，CI通过后才发布。旧导航文案、部长排班只读授权及过时的验收定位已同步到当前功能，未放宽权限或数据断言。

隔离API冒烟、备份恢复、远程入口限制及真实后端四角色页面/接口权限回归已通过。前端核心工作流冒烟使用夹具，不能单独作为后端权限证明。测试数据由本次发布获准使用的专用临时库产生，不复制现有业务库，也不对其执行破坏性测试；临时库在测试结束后清理。

七套主题已完成主要页面、窄窗、对话气泡、导出配置与结果滚动、详情卡片和键盘焦点检查；这些代表检查不等于全部页面、角色和子弹窗的完整组合验收。

成品桌面稳定性已验证托盘隐藏/恢复/完全退出、单实例、8080/8081回环绑定、后端异常退出、目录迁移、窗口缩放与状态恢复。七套主题均在真实Electron成品中保存并检查登录、签到、主要后台页面及100%/125%/150%缩放；维修和培训保存后刷新仍在，协议可预览，培训名单可从数据中心导出；重启后数据与最后的主题保留。

大数据检查覆盖500个账号、10000条值班记录、200场培训（含3000人名单）、1100条维修及5000条日志。API和浏览器绝对性能阈值、分页/查询/导出/权限/恢复校验、四种窗口尺寸的根溢出与信息区重叠检查通过；本次没有可比历史基线，不据此宣称性能提升。

前端生产与完整依赖审计、桌面生产审计无告警；桌面完整审计没有高危或严重告警，仍存在`sprintf-js`格式化参数导致未捕获异常的中危告警及其构建依赖关联项。该依赖位于electron-builder下载工具的代理日志链路，成品`app.asar`不包含它及关联包。未通过强制降级更改构建工具。详情见[官方公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。

成品ASAR版本、便携ZIP与程序文件、空数据目录及SHA-256校验已核对。安装器实际安装/卸载和跨版本安装向导、两种Windows系统、物理断网、全部系统DPI及多显示器场景尚未完整验证；未修改当前已安装程序。

安装包未代码签名，Windows可能提示未知发布者；SQLite主库与备份未加密。
