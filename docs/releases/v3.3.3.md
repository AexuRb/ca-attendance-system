# v3.3.3 - 工作区体验与导入模板完善

发布日期：2026-10-07。Windows 10/11 x64 为支持目标。

本版包含统计查找、排序、成员记录追溯与连续核对，整周排班与按日编辑切换，培训场次日期分组和完整标题，以及首页提醒展开。Classic、Editorial、Spatial 继续共用业务规则并保留各自布局。

成员导入新增服务端预览与确认，确认时重新读取文件并校验资料版本；会长导入跳过管理员行，其他错误仍整批不写入。已有成员的空白可选字段保留原资料，角色、状态与密码不由基础资料导入修改。部长统计来源仅开放培训日期、标题和个人计入时长，不开放培训管理、参与名单或备注。

成员静态模板保留六列，使用学院字段、文本数据区、独立填写示例和年级下拉。排班及培训模板仍由后端动态生成，保留四列契约与培训主讲人预填，完善文本学号、匹配、当前默认时长、整组替换或记录更新、5 MB 和行数限制的填写说明。

## 升级与回滚

无新增数据库迁移或运行依赖。升级前从托盘完全退出程序，并保留当前 `data` 与 `backups`；安装器保留数据目录。便携版仅替换程序目录，避免覆盖业务数据。请重新下载导入模板，具体培训模板的预填信息仍需核对目标场次。

回滚时保留数据，再从上一版本 Release 替换程序目录；无法启动或出现数据问题时优先使用升级前备份，不手工修改 SQLite。

## 验证与发行边界

本地后端全量测试及依赖上界、前端全量测试及应用/测试类型检查、桌面测试、仓库脚本测试与语法检查均通过，前端生产构建和 Windows 安装版/便携版构建完成。测试结果从本轮运行报告读取，不沿用历史数量。

新 JAR 的隔离 API 冒烟覆盖成员、排班、签到审核、培训、维修、导出、备份恢复与审计；远程角色与锁定限制检查通过。夹具驱动的核心页面冒烟通过桌面及窄屏检查，并验证未保存草稿的取消保留与确认放弃；它不作为后端权限证明。另行执行的真实后端 UI 角色回归通过页面入口、直接路由及 API 边界检查。

合成大数据的 API、浏览器性能、数据库及 Java 内存通过绝对阈值；长培训标题、3000 人名单、维修分页/导出及四种视口检查通过，无所检横向溢出、单元格重叠或控制台错误。本轮没有历史性能基线比较。三主题受影响页面及模拟缩放沿用本次开发阶段的实际浏览器复核，未重复全部页面/角色组合。

发行 JAR 的类文件和静态资源、ASAR 源文件、Java 运行时、便携 ZIP 程序文件及空数据目录已逐文件核对；安装版和便携版 SHA-256 与校验文件一致。构建在仓库外快照完成，因为当前运行的旧后端锁定原工作区 JAR；未中断它或修改正式数据。

桌面稳定性脚本因当前系统占用 8080/8081 在启动前停止，本轮未完成新桌面程序的托盘、单实例、异常退出、目录迁移及便携版实际启动/重启验收，不宣称完整发布门禁通过。原生 Excel/WPS、Windows 文件对话框和下载目录、安装向导与跨版本安装/卸载、物理断网、原生缩放/DPI、多显示器及两种 Windows 系统的完整覆盖也未确认。

前端生产及完整依赖审计无告警；桌面生产审计无告警，完整审计无高危或严重告警。桌面完整审计仍有 sprintf-js 拒绝服务及其构建依赖关联项的中危告警；嵌套 @electron/get → global-agent → roarr 的代理日志链路使用该包，应用 ASAR 不含这些构建依赖。本轮未改变依赖，不以强制降级消除告警。
