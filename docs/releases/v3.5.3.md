# v3.5.3 - 弹窗、联系方式与统计体验维护

## 本版变化

- 统一编辑、确认、上传、恢复与详情弹窗的外壳、滚动和操作区；完善失败提示、提交期间的关闭保护及重新打开清理。
- 成员选择支持紧凑的已选摘要、每页6人、加载失败重试与键盘选择；排班多选跨页保留，已选名单可展开。原因圆圈保留用户确认的主题扫光反馈。
- 签到/签退驳回、值班记录补录/修改/删除、成员修改/批量启停/删除使用固定原因和“其他”必填说明；失败保留原输入，后端权限、审计和危险确认规则保持。
- 值班记录初次加载不再显示交替行底色，悬停采用轻量主题色；数据统计按实际工作区宽度切换完整表格、紧凑表格和卡片。
- 电话和QQ均可留空；填写时电话为11位大陆手机号，QQ为5—20位数字且首位非0。个人资料、成员编辑及成员导入使用同一规则；长QQ须在Excel中按文本填写，避免数字精度丢失。
- 旧备份恢复前检查联系方式，显示错误数量并可展开明细。明确同意清空且完成原恢复确认后，仅清空错误电话/QQ；确认与文件摘要绑定，原备份文件及其他数据保持，失败恢复与审计事务边界保留。
- Electron由43.7.7更新至43.8.7，包含[中间证书信任修复](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9)；同步更新Vite、Vitest、undici及fast-uri等开发/构建依赖。既有下载代理兼容补丁及严格TLS校验保留。

## 升级与回滚

无新增数据库迁移，继续使用原数据库。升级前从托盘完全退出，备份并保留data与backups；安装版保留数据，便携版仅替换app目录。回滚先保留当前数据，再使用上一版程序及必要时的升级前备份，不手工修改SQLite。

主题字体引起的偶发窗口错位按用户要求暂缓；维修事务导出、培训记录导出与今日概览后续改版继续保留待办。
