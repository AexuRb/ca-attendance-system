# 换届交接清单

## 1. 交接原则

换届交接应在主机现场完成。账号密码、远程隧道凭据和真实备份不得写入 GitHub、聊天记录或公开文档。毕业或不再参与协会工作的账号应停用，不应为了保留历史数据而继续保持登录权限。

## 2. 交接前准备

- [ ] 从托盘菜单选择“完全退出”，确认 `127.0.0.1:8080` 和 `127.0.0.1:8081` 已停止监听。
- [ ] 复制整个 `CAAttendance` 目录到受控存储，或在后台创建一次完整备份并另存到安全位置。
- [ ] 使用管理员账号检查最近一次备份能够出现在恢复列表中。
- [ ] 记录当前程序版本、Windows 版本和主机存放位置。
- [ ] 检查 `data/attendance.db` 不在网盘公开目录或 Git 仓库中。

## 3. 账号与角色

- [ ] 确认至少保留两个可用的管理员账号，避免唯一管理员遗失密码。
- [ ] 将当届会长任命为管理员；会长角色只用于退休会长，不得由会长任命管理员。
- [ ] 将当届和退休部长按实际需要保留为部长；毕业或离开协会后停用账号。
- [ ] 复核普通成员、部长、会长和管理员列表，删除错误角色并停用无继续访问需要的账号。
- [ ] 新负责人现场修改自己的初始密码，不通过明文文件传递密码。
- [ ] 验证部长不能进入成员页面或排班页面，会长不能维护管理员账号。

## 4. 日常业务核对

- [ ] 在“系统 > 设置”核对值班星期、值班时段和值班限制开关。
- [ ] 在“值班 > 排班”核对固定周表与签到台展示一致。
- [ ] 核对最近一周签到、审核和有效时长汇总。
- [ ] 核对未完成维修事务、培训记录和待处理签到。
- [ ] 现场执行一次测试签到和签退，确认主机签到台可用。

## 5. 远程管理交接

- [ ] 樱花穿透只转发 `127.0.0.1:8081`，不得转发 `8080`。
- [ ] 远程打开后只能进入后台登录，不能看到签到台、初始化页或桌面控制接口。
- [ ] 只有会长和管理员账号能够从远程入口登录。
- [ ] 交接隧道账号后修改密码或访问密钥，并从旧负责人设备退出登录。
- [ ] 不需要远程管理时关闭隧道，避免无意义暴露。

## 6. 恢复与迁移演练

- [ ] 在测试目录或备用电脑中复制完整应用目录并启动。
- [ ] 确认成员、设置、固定排班和最近业务数据存在。
- [ ] 使用一份测试备份完成恢复演练，确认恢复后需要重新登录。
- [ ] 核对新目录中的 `logs/desktop.log` 和 `logs/backend.log` 能正常写入。
- [ ] 记录演练日期、执行人和结果，但不记录成员隐私或密码。

## 7. 交接完成确认

- [ ] 新负责人能够独立完成启动、托盘退出、备份、恢复和整目录迁移。
- [ ] 新负责人知道安装包无签名，需要核对正式 Release 的 SHA-256。
- [ ] 旧负责人已移除不再需要的本机文件、隧道会话和管理员权限。
- [ ] 双方确认业务数据、账号、备份和远程隧道均已完成交接。
