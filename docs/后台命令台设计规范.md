# 后台命令台设计规范

本文档定义计算机协会本地管理系统后台首页命令台的完整交互与命令契约。命令台用于快速打开页面、应用筛选、查找业务记录和预填操作，不是操作系统终端，也不直接访问数据库、文件系统或后端内部接口。

本文档是命令台的长期设计与验收基线，不记录临时开发进度。角色授权以[角色权限矩阵](角色权限矩阵.md)为准，视觉和动效以[前端视觉规范](前端视觉规范.md)为准；实现状态、测试结果和阶段待办统一记录在 `DEV_STATE.md`。

## 范围与边界

命令台供已登录的部长、会长和管理员在桌面、本机 Web 或受限远程后台使用；成员不开放完整命令台，如在个人页复用仅开放自己的资料、值班及培训记录。远程端不得访问签到台、初始化或桌面控制。

使用中文动词和现有页面名称，同一输入框完成搜索、导航、筛选与表单预填。命令不直接访问数据库、文件系统或后端内部接口，不替代页面校验、权限、确认、审计及事务。写入、文件生成和备份创建必须经用户明确确认。

## 交互模式

### 输入模式

普通文字做功能模糊搜索，仅推荐当前角色可访问的结果，明确选中后才执行。半角 `/` 是唯一命令入口，例如 `/ 查看 值班记录 本周`；显示“命令”状态，外观沿用当前主题。

### 键盘操作

| 操作 | 行为 |
| --- | --- |
| `/` | 命令台已聚焦时进入命令模式；焦点不在可编辑控件且未处于输入法组合状态时，聚焦命令台并进入命令模式 |
| ↑ 或 ↓ | 在当前建议中移动选择 |
| Tab | 补全当前活动参数并进入下一级；没有可补全参数时按正常焦点顺序移动 |
| → | 光标位于当前参数末尾且存在尾字补全时，接受尾字并进入下一级；其他情况正常移动光标 |
| Enter | 命令完整且合法时执行；命令不完整且用户已明确选中建议时，只补全当前参数，不提前执行 |
| Backspace | 正常删除；当前参数为空且位于分隔空格之后时，返回上一级并恢复对应建议 |
| Esc | 第一次关闭建议，第二次清空输入并退出命令模式 |

`/` 的全局行为只在后台页面的非编辑状态下生效。在其他输入框、文本域、下拉框、可编辑区域、文件选择器和中文输入法组合过程中，该按键必须保留原有输入含义，不得抢占焦点；命令台自身输入框是唯一例外。

命令建议使用单一 roving tab stop。鼠标悬停可以显示悬停样式，但不能改变键盘已选中的结果，除非用户点击该结果。中文输入法尚未完成组合时，Enter、Tab、方向键和 `/` 均不得触发命令台执行、补全或切换。

## 命令语法

格式：`/ {动作} {对象} [范围] [状态] [关键词]`，例如 `/ 查找 成员 "示例成员"`。

### 确定性解析

- 移除半角 `/` 后规范化首尾、连续、全角空格及常见中文标点；中文引号、英文单双引号内视为单一关键词并保留原值。
- 固定动作在前、对象在后：动作精确匹配 → 对象最长规范名/别名 → 对象专用参数，不接受任意自然语言。仅剩一个完整词时才使用快捷命令，优先级低于完整解析。
- 日期、状态、星期与对象别名先规范化再判权限，不能改变命令身份、等级或权限；模糊匹配只用于建议，不参与最终执行。
- 缺少、重复、未知或不属于当前对象的参数报错；别名不能在同角色范围内歧义或与动作、对象、快捷词冲突。

### 命令注册表契约

每条可执行命令必须具有稳定的命令 ID，并在运行时注册表中完整声明以下字段：

| 字段 | 要求 |
| --- | --- |
| `id` | 稳定且全局唯一，不因显示文案调整而变化 |
| 动作与对象 | 使用规范名称，并列出允许的无歧义别名 |
| 角色 | 明确允许角色；前端过滤不能替代后端授权 |
| 参数 | 明确参数名称、类型、顺序、必填性、默认值和可接受枚举 |
| 节点 | 声明节点类型、合法父节点、合法子节点和是否可执行 |
| 执行等级 | 固定为 A、B、C 或 D，不得由输入内容临时降低 |
| 目标 | 明确目标路由、页面意图和允许写入 URL 的查询参数 |
| 敏感性 | 标记不得写入 URL、历史、日志或持久化存储的参数 |
| 反馈 | 明确成功结果、错误信息和无匹配时的处理方式 |

`frontend/src/features/command-center/commandCatalog.ts` 是运行时命令注册的唯一来源，本文件中的命令表是对外行为和验收快照。新增、删除、重命名命令或别名时，必须同步更新注册表、解析测试、权限测试和本文档；任一处不一致即视为未通过验收。

注册表必须具有自动化唯一性检查，至少覆盖命令 ID、规范对象、对象别名和单词快捷命令冲突。对象专用参数应由注册表或同一模块中的显式解析规则定义，不得依赖页面根据自由文本再次猜测。

### 命令树与活动参数

由注册表生成角色感知树：入口 → 动作 → 对象 → 对象专用参数 → 可执行状态。

- 只建议当前节点合法直接子节点；动作至少有一个授权对象，对象同时受动作和角色过滤；参数区分枚举、日期、星期、状态、关键词和完整编号。
- 必填未完成不可执行，可选参数默认值显示在摘要中；树无循环，同一路径不能对应多个命令 ID。
- 光标决定活动参数，建议/错误随之同步；接受建议只替换该参数，保留前后内容，别名补全为规范名。点击建议只补全，完整后仍须 Enter 或执行按钮确认。
- 姓名、学号、电话、维修编号和自由关键词由用户输入，只提示参数要求，不枚举或请求业务数据。

## 动作与执行等级

| 动作 | 用途 | 等级 | 行为 |
| --- | --- | --- | --- |
| 打开 | 打开页面或功能区 | A | 可立即导航 |
| 查看 | 打开页面并应用范围或状态 | A | 可立即导航并筛选 |
| 查找 | 打开页面并填写关键词 | A | 可立即导航并查询 |
| 预览 | 打开只读预览 | A | 找到唯一目标后打开预览 |
| 新建 | 创建业务记录 | B | 只打开并预填表单，用户手动提交 |
| 导入 | Excel 导入 | B | 只打开导入窗口，用户选择文件并确认 |
| 导出 | Excel 导出 | C | 打开导出预览，用户确认后生成文件 |
| 设置 | 定位系统设置 | B | 只打开并定位设置项，用户手动保存 |
| 创建 | 创建安全备份 | C | 显示确认弹窗后执行 |

执行等级的副作用契约：

| 等级 | 允许行为 | 确认前请求 | 禁止行为 |
| --- | --- | --- | --- |
| A | 导航、设置非敏感筛选、读取当前角色有权查看的数据 | 只允许目标页面原有的只读请求 | 写入业务数据、生成文件或打开危险确认 |
| B | 导航、打开表单或导入窗口、预填命令中明确提供的字段 | 不允许业务写请求 | 自动提交、自动选文件、自动保存设置 |
| C | 导航并展示导出预览或应用内确认 | 确认前只允许计算范围、数量或预览所需的只读请求 | 确认前生成文件、创建备份或产生其他写入 |
| D | 显示拒绝原因和安全的前往页面提示 | 不允许发送目标业务请求 | 导航到危险确认、预填危险操作或执行任何副作用 |

同一条命令在一次执行尚未结束时不得再次执行。Enter、鼠标点击和触摸操作必须共享同一个执行锁；C 级命令确认后只允许发出一次写入或下载请求。关闭 B、C 级界面必须回到命令执行前的业务状态，已经确认并完成的下载或备份不宣称可撤销。

## 标准参数

### 时间范围

| 输入 | 解析结果 |
| --- | --- |
| 今天 | 当前本地日期 |
| 昨天 | 当前本地日期前一天 |
| 本周 | 当前自然周 |
| 上周 | 上一个自然周 |
| 本月 | 当前自然月 |
| 上月 | 上一个自然月 |
| 2026-08-28 | 指定日期 |
| 2026-08-01..2026-08-28 | 包含首尾日期的闭区间 |
| 2026年8月 | 2026-08-01 至 2026-08-31 |
| 2026年 | 2026-01-01 至 2026-12-31 |

开始日期晚于结束日期时应阻止执行，并提示“开始日期不能晚于结束日期”。

### 其他参数

| 参数 | 规则 |
| --- | --- |
| 星期 | 周一至周日；“星期一…日”“礼拜一…日”规范化为“周一…日” |
| 值班状态 | 仅“待审核”“未签退”；已通过、自动通过、已驳回仅在编辑界面显示，命令不修改状态 |
| 维修状态 | 进行中、已完成、已取消；“取消”规范化为“已取消” |
| 成员状态 | 启用、停用，仅筛选，不修改账号状态或角色 |
| 关键词 | 姓名、学号、维修编号及普通关键词均按字符串；含空格须引号，`%`、`_`、反斜线按字面；建议不得越权显示个人资料 |

## 部长、会长和管理员通用命令

以下命令对部长、会长和管理员开放。

| 规范命令 | 等级 | 结果 |
| --- | --- | --- |
| `/ 打开 今日概览` | A | 打开今日概览 |
| `/ 打开 签到审核` | A | 打开当前角色可处理的完整待审核队列，包含历史记录；不限定今日 |
| `/ 查看 值班记录 [范围]` | A | 打开值班记录并应用今天、昨天、本周、上周、本月、上月、指定日期或日期区间 |
| `/ 查看 值班记录 待审核 [范围]` | A | 按待审核状态与可选日期范围查看；省略范围时沿用记录页默认日期 |
| `/ 查看 值班记录 未签退 [范围]` | A | 按未签退状态与可选日期范围查看，例如 `/ 查看 值班记录 未签退 今天`；省略范围时沿用记录页默认日期 |
| `/ 查找 值班记录 {关键词}` | A | 按姓名或学号查找记录 |
| `/ 查看 数据统计 [范围]` | A | 打开数据统计；支持今天、昨天、本周、上周、本月、上月、本年、指定日期或日期区间，缺省为本周 |
| `/ 导出 数据统计 [范围]` | C | 打开标准统计导出预览 |
| `/ 打开 维修事务` | A | 打开维修事务，缺省状态为进行中 |
| `/ 查看 维修事务 [{状态}] [范围]` | A | 按进行中、已完成或已取消及可选日期范围查看维修事务；状态缺省为进行中 |
| `/ 查找 维修事务 {关键词}` | A | 按编号、姓名、设备或故障关键词查找 |
| `/ 新建 维修事务` | B | 打开空白维修事务表单 |
| `/ 预览 维修协议 {维修编号}` | A | 找到唯一记录后打开协议预览 |
| `/ 打开 个人资料` | A | 打开当前账号个人资料 |

部长后续页面操作边界见 [角色权限矩阵](角色权限矩阵.md)，命令入口不增加业务权限。

## 单词快捷命令

单独输入以下稳定快捷词时，转换为对应规范命令。快捷词必须是完整单词，不能在带有其他参数时抢占标准解析：

| 输入 | 等价命令 |
| --- | --- |
| `/ 今日` | `/ 打开 今日概览` |
| `/ 审核` | `/ 打开 签到审核` |
| `/ 考勤` | `/ 查看 值班记录 本周` |

## 自动补全与排序

补全完全基于本地注册表：按会话角色过滤 → 当前节点合法子节点 → 规范名精确、规范名前缀、别名精确/前缀、名称包含匹配；同级优先当前页面，再按注册表稳定顺序。输入、移动光标和切换建议不得请求后端，完整命令明确执行后才按等级发请求。

### 补全状态

| 状态 | 界面行为 | Enter 行为 |
| --- | --- | --- |
| 等待动作 | 展示当前角色允许的动作 | 不执行；明确选中后补全动作 |
| 等待对象 | 只展示该动作支持且当前角色可用的对象 | 不执行；明确选中后补全对象 |
| 等待参数 | 展示当前参数类型、合法枚举或输入要求 | 不执行；枚举可补全，自由文本等待输入 |
| 命令完整 | 展示结果摘要和执行等级 | 执行当前精确命令 |
| 参数错误 | 标出错误参数并展示该位置的合法建议 | 不执行 |
| 无权限 | 不展示受限数据，只显示稳定的无权限反馈 | 不执行 |

完整精确输入优先于建议；普通搜索只执行明确选择的结果。新参数层级默认无明确选择，Tab 可接受首条合法建议，方向键建立选择，继续输入清除旧选择；未明确选择的建议不得替换输入。

### 建议与历史

- 最多 6 条建议，显示规范参数名、类型及一行直接结果，仅能形成完整命令时显示执行等级。禁止业务敏感信息、内部表名/接口/枚举、密码/令牌/绝对路径和可直接执行的危险入口。
- 唯一规范名前缀匹配才显示尾字；尾字不进入输入值、读屏或提交，接受 Tab、符合条件的右方向键或点击后才写入规范参数。
- 空搜索最多 5 条当前角色高频功能；输入 `/` 后只展示第一层动作。历史仅存会话内存，退出、刷新、角色变化或关闭应用后清除，不用于补全业务关键词。

## 执行流程

### 导航与预填

先解析、规范化、鉴权，再生成目标路由和页面意图。A 级导航后给简短反馈；B 级只打开界面并预填明确给出的字段，用户手动提交，取消不写入。培训参与人员导入必须由页面选择具体场次，不能以模糊关键词确定目标。

URL 仅保存日期、状态、星期、分页、页签等非敏感筛选，刷新可恢复。姓名、学号、电话、维修编号、自由关键词及派生查询只在页面内存传递，不进 URL、路由历史或持久存储，刷新、退出或角色变化后清除。

### 导出与备份

C 级先检查权限/参数，展示范围、状态、数据源和文件类型，应用内确认后调用原业务流程并用统一 Toast 反馈。导出上限仍为 50,000 行；已有范围核对及确认入口可复用，不要求新增预览页，没有确认流程不得直接生成文件。

### 并发、重复执行与失败恢复

1. 同一命令台同一时间只允许一个执行流程处于进行中。
2. Enter、鼠标点击和触摸必须共享执行锁；重复操作不得产生重复导航、重复弹窗、重复下载或重复写入。
3. 新输入产生后，较早的异步解析或读取结果必须取消或忽略，不能覆盖较新的建议和反馈。
4. 导航失败时保留原命令；服务失败时只保留非敏感参数，敏感参数不得跨刷新或重新登录恢复。
5. B、C 级弹窗已经打开时，再次执行同一命令应聚焦现有弹窗，不得叠加第二个实例。
6. 会话过期、账号停用或角色变化时立即终止待执行流程，清除敏感输入并按现有会话流程处理。

### 目标匹配

- 姓名、学号或普通关键词出现多个结果时，只打开当前角色有权访问的过滤列表，不自动选中第一条记录。
- 维修协议预览必须使用完整维修编号并匹配唯一记录；不存在时不打开预览，出现异常重复时展示经过权限裁剪的选择列表。
- 建议和选择列表只显示完成区分所必需且当前角色原本可见的字段。同名成员优先显示脱敏学号，不增加联系电话等无关信息。
- 找不到目标时不得退化为更宽泛的写操作、默认选择或相似编号。

## 禁止直接执行的命令

以下动作即使语法正确，也只能提示用户前往对应页面：

    删除 永久删除 清空 恢复 停用 启用 任命 重置密码
    通过审核 驳回审核 批量审核 修改记录 修改角色 修改值班时间

例如输入：

    / 删除 成员 1001

应返回：

    命令台不直接执行成员删除，请前往成员名册核对后操作。

不得把危险命令自动改写成相似的安全命令，也不得在提示后自动打开确认弹窗。

## 错误反馈

| 场景 | 建议反馈 |
| --- | --- |
| 未识别动作 | 无法识别动作“处理”，可使用打开、查看、查找、新建、导入、导出或设置。 |
| 未识别对象 | 没有找到“事务中心”，请从建议中选择现有功能。 |
| 缺少关键词 | “查找成员”需要姓名或学号。 |
| 缺少维修编号 | 预览维修协议需要完整维修编号。 |
| 日期反转 | 开始日期不能晚于结束日期。 |
| 状态不支持 | 维修状态只支持进行中、已完成或已取消。 |
| 无权限 | 当前角色无权使用“成员名册”。 |
| 目标不存在 | 没有找到匹配的维修事务。 |
| 多个结果 | 找到多个结果，请补充编号或从列表中选择。 |
| 危险操作 | 命令台不直接执行该操作，请前往对应页面核对。 |
| 服务不可用 | 本机服务暂时不可用，命令和输入已保留，可稍后重试。 |
| 导出超限 | 导出结果超过 50,000 行，请缩小日期或状态范围。 |

错误发生后应保留原命令并选中第一个错误参数，便于用户直接修改。

## 权限与安全

- 前端过滤不替代后端实时授权；401/403、账号状态变化或会话刷新后重新获取会话并重建建议，使旧建议和待执行命令失效；账号停用也使已有页面请求失效。
- 查询仅展示页面原本授权的必要字段。命令文本不进普通操作日志，敏感参数不进页面标题、普通日志或错误遥测；真实写入沿用业务审计，URL/历史边界见执行流程。
- 参数不得拼接为 HTML、SQL、文件路径或系统命令。远程入口、校验、导入导出上限、确认及事务边界与普通页面一致。

## 视觉与动效

统一见 [前端视觉规范](前端视觉规范.md#后台命令工作区)，本文件不重复维护位置、尺寸、颜色和动画参数。

## 无障碍

- 输入有真实可访问名称与 combobox 语义，维护 `aria-controls`、`aria-expanded`、`aria-autocomplete="list"`、`aria-activedescendant`；建议用 listbox/option，键盘选择与鼠标悬停独立。
- 全流程可键盘操作，关闭后回焦；输入法组合期间不执行或移动建议。结果/错误用礼貌级 live region 播报，接受补全播报参数及下一要求，完整命令播报摘要和等级；权限错误不只用颜色表达。
- Windows 125%/150%、浏览器 200% 缩放及 680px 窄屏下文字与操作不重叠。

## 验收清单

按本文契约验证解析、权限、A–D 级副作用、键盘/输入法、失败恢复、隐私与离线。尤其检查无权命令不发请求、C 级确认前无写入/文件生成、重复执行只提交一次，不能只验证正常导航。

### 数据驱动契约测试

命令注册表测试至少应为每条命令记录以下断言：

| 字段 | 验证内容 |
| --- | --- |
| 输入 | 半角 `/` 前缀、逐级补全路径、规范写法及允许别名 |
| 角色 | 允许角色、拒绝角色及权限变化后的失效行为 |
| 规范化结果 | 稳定命令 ID、规范动作、对象和参数 |
| 导航结果 | 目标路由、允许的 URL 参数和页面意图 |
| 执行等级 | A、B、C、D 及确认前允许的请求数量和类型 |
| 反馈 | 成功、参数错误、无权限、无结果和多结果文案 |

测试数据必须覆盖逐级节点过滤、光标中途编辑、Tab 与尾字补全、返回上一级、全角标点、引号、闰年与无效日期、重复参数、额外参数、别名冲突、连续执行、会话过期、角色变化、输入法组合、窄屏、缩放和 `prefers-reduced-motion`。任何敏感关键词进入建议、URL 或持久化历史都应直接判定为失败。

## 预留扩展能力

以下命令方向需要新增或确认业务语义，不属于当前正式命令契约。运行时注册表、普通搜索和命令树在对应接口、权限、隐私与验收测试完成前不得展示这些节点。

| 预留命令 | 前置条件 | 预期等级 |
| --- | --- | --- |
| `/ 查看 我的值班 [范围]` | 明确“我的”仅绑定当前登录账号，并确认部长、会长和管理员的查询边界 | A |
| `/ 查看 维修事务 超期` | 定义维修期限、暂停时间、取消记录和超期计算规则，并由后端返回稳定筛选条件 | A |

## 版本与变更治理

- 命令注册表必须声明独立的契约版本。纯显示文案调整可以保持版本不变；修改前缀、语法、命令 ID、参数含义、权限或执行等级时必须提升契约版本。
- 已发布的稳定命令 ID 不得复用给其他含义。对象或别名需要废弃时，应先保留一个明确的兼容周期并显示替代提示，再在后续版本移除。
- 新增、删除或调整命令时，必须同时检查命令注册、解析测试、角色权限测试、页面意图、本文档命令表和验收矩阵。
- 规范中未列出的命令属于预留能力，不得因为存在相似页面或后端接口而自动暴露。
- 命令入口、权限或副作用契约发生变化时，应在 `DEV_STATE.md` 记录当前实现状态；临时进度和发布说明不回写本规范。
