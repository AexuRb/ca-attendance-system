# 后台命令台设计规范

本文档定义计算机协会本地管理系统后台首页命令台的完整交互与命令契约。命令台用于快速打开页面、应用筛选、查找业务记录和预填操作，不是操作系统终端，也不直接访问数据库、文件系统或后端内部接口。

本文档是命令台的长期设计与验收基线，不记录临时开发进度。角色授权以[角色权限矩阵](角色权限矩阵.md)为准，视觉和动效以[前端视觉规范](前端视觉规范.md)为准；实现状态、测试结果和阶段待办统一记录在 `DEV_STATE.md`。

## 1. 适用范围

- 命令台放置在已登录的后台首页，适用于部长、会长和管理员。
- 普通成员不进入后台首页，因此不提供完整命令台；若以后在个人资料页复用，只能开放个人资料、个人值班记录和个人培训记录。
- 命令台可用于 Windows 桌面端、本机 Web 后台和受限远程后台。
- 远程后台继续遵守原有角色权限，不得通过命令访问签到台、初始化页面或桌面控制功能。
- 命令台不得替代现有表单校验、确认弹窗、权限检查、操作日志和事务边界。

## 2. 设计目标

1. 使用中文动词和现有页面名称，降低学习成本。
2. 同一个输入框同时承担功能搜索和命令输入，不新增笨重终端面板。
3. 高频导航和筛选可以一次完成，创建类操作只负责打开并预填表单。
4. 命令结果按当前角色过滤，无权命令不得泄露页面数据。
5. 危险写操作不能因输入一条命令而直接执行。
6. 命令必须可预测并提供明确反馈；导航和预填操作可以无副作用地退出，写入、文件生成或备份创建必须在用户明确确认后发生。

## 3. 交互模式

### 3.1 功能搜索

输入普通文字时进入功能搜索模式，例如：

    签到
    维修
    成员

搜索结果显示当前角色可访问的页面和功能。功能搜索允许模糊匹配，但只负责推荐，不在没有明确选中结果时执行操作。

### 3.2 命令模式

输入内容以半角斜杠 `/` 开头时进入命令模式：

    / 查看 值班记录 本周
    / 查找 维修事务 JXWX20260828-0001

界面应明显显示“命令”状态，但继续使用现有淡蓝色设计，不切换为黑色终端。

`/` 是唯一的命令模式入口。

### 3.3 键盘操作

| 操作 | 行为 |
| --- | --- |
| `/` | 命令台已聚焦时进入命令模式；焦点不在可编辑控件且未处于输入法组合状态时，聚焦命令台并进入命令模式 |
| ↑ 或 ↓ | 在当前建议中移动选择 |
| Tab | 补全当前活动参数并进入下一级；没有可补全参数时按正常焦点顺序移动 |
| → | 光标位于当前参数末尾且存在尾字补全时，接受尾字并进入下一级；其他情况正常移动光标 |
| Enter | 命令完整且合法时执行；命令不完整且用户已明确选中建议时，只补全当前参数，不提前执行 |
| Backspace | 正常删除；当前参数为空且位于分隔空格之后时，返回上一级并恢复对应建议 |
| Esc | 第一次关闭建议，第二次清空输入并退出命令模式 |

`/` 的全局行为只在后台页面的非编辑状态下生效。在其他输入框、文本域、下拉框、可编辑区域、文件选择器和中文输入法组合过程中，该按键必须保留原有输入含义，不得抢占焦点；命令台自身输入框是唯一例外。

命令建议使用单一 roving tab stop。鼠标悬停可以显示悬停样式，但不能改变键盘已选中的结果，除非用户点击该结果。中文输入法尚未完成组合时，Enter、Tab、方向键和 `/` 均不得触发命令台执行、补全或切换。

## 4. 命令语法

标准格式：

    / {动作} {对象} [范围] [状态] [关键词]

示例：

    / 打开 签到审核
    / 查看 值班记录 本周
    / 查看 维修事务 进行中
    / 查找 成员 "示例成员"
    / 导出 数据统计 2026-08-01..2026-08-28

### 4.1 确定性解析规则

1. 动作和对象之间使用一个或多个空格分隔。
2. 半角 `/` 是唯一命令前缀，解析后移除前缀再处理动作、对象和参数。
3. 中文引号、英文双引号和英文单引号中的内容视为一个关键词。
4. 连续空格、首尾空格、全角空格和常见中文标点在解析前统一规范化；引号内内容保持原值。
5. 先精确匹配动作，再按最长名称或别名匹配对象，最后按该对象的参数定义解析剩余内容。
6. 日期、状态、星期和对象别名在权限判断前转换为规范名称；别名不能改变命令身份、执行等级或角色权限。
7. 规范命令采用“动作在前、对象在后”的固定顺序；不支持任意自然语言句式。
8. 单词快捷命令只在规范化后恰好剩余一个完整词时生效，其优先级低于完整的动作和对象解析。
9. 模糊匹配只能生成建议，不能参与最终执行解析，也不能猜测并自动执行写操作。
10. 缺少、重复、不属于当前对象或无法识别的参数均应返回错误，不能静默忽略。
11. 对象别名之间不得在同一角色范围内产生歧义；新增别名与现有动作、对象和快捷命令冲突时不得注册。

### 4.2 命令注册表契约

每条可执行命令必须具有稳定的命令 ID，并在运行时注册表中完整声明以下字段：

| 字段 | 要求 |
| --- | --- |
| `id` | 稳定且全局唯一，不因显示文案调整而变化 |
| 动作与对象 | 使用规范名称，并列出允许的无歧义别名 |
| 角色 | 明确允许角色；前端过滤不能替代后端授权 |
| 参数 | 明确参数名称、类型、顺序、必填性、默认值和可接受枚举 |
| 节点 | 声明节点类型、合法父节点、合法子节点和是否可执行 |
| 执行等级 | 固定为 A、B、C 或 D，不得由输入内容临时降低 |
| 目标 | 明确目标路由、页面意图和允许写入 URL 的查询参数 |
| 敏感性 | 标记不得写入 URL、历史、日志或持久化存储的参数 |
| 反馈 | 明确成功结果、错误信息和无匹配时的处理方式 |

`frontend/src/features/command-center/commandCatalog.ts` 是运行时命令注册的唯一来源，本文件中的命令表是对外行为和验收快照。新增、删除、重命名命令或别名时，必须同步更新注册表、解析测试、权限测试和本文档；任一处不一致即视为未通过验收。

注册表必须具有自动化唯一性检查，至少覆盖命令 ID、规范对象、对象别名和单词快捷命令冲突。对象专用参数应由注册表或同一模块中的显式解析规则定义，不得依赖页面根据自由文本再次猜测。

### 4.3 命令树与活动参数

命令台使用一棵由注册表生成的角色感知命令树，不使用互相独立的整句候选列表。标准路径为：

```text
命令入口 → 动作 → 对象 → 对象专用参数 → 可执行状态
```

每一级只允许展示当前节点的合法直接子节点：

| 当前输入 | 当前节点 | 允许建议示例 |
| --- | --- | --- |
| `/` | 动作 | 打开、查看、查找、新建、导入、导出、设置、创建 |
| `/ 查` | 动作 | 查找 |
| `/ 查看 ` | 对象 | 值班记录、数据统计、维修事务、培训记录 |
| `/ 查看 值班记录 ` | 参数 | 今天、本周、上周、待审核、未签退 |
| `/ 查看 值班记录 本周` | 可执行 | 不再追加无关参数，显示执行结果摘要 |

命令树规则：

1. 动作节点只包含当前角色至少有一个可用对象的动作；没有合法子节点的动作不展示。
2. 对象节点同时受动作支持范围和角色权限过滤。例如“新建”之后不能提示不支持新建的对象。
3. 参数节点由对象专用参数模式产生，区分枚举、日期范围、星期、状态、关键词和完整编号。
4. 必填参数尚未完成时，节点不可执行；可选参数缺省值必须在结果摘要中明确显示。
5. 当前活动参数由光标位置决定。移动光标到前一个参数时，建议和错误必须随之回到该参数层级。
6. 接受建议时只替换当前活动参数，保留前后其他已输入参数，不得用整条预设命令覆盖输入框。
7. 别名可以参与当前参数匹配，但补全后统一写入规范名称。
8. 命令树不得形成循环，也不得让同一输入路径对应多个命令 ID。
9. 点击建议只补全当前参数；即使补全后命令已经完整，也必须再按 Enter 或点击执行按钮才执行。

姓名、学号、电话、维修编号和自由关键词属于手动参数，不进入静态建议列表。界面只显示“输入姓名或学号”“输入完整维修编号”等参数要求，不在输入过程中请求或枚举真实业务数据。

## 5. 动作与执行等级

| 动作 | 用途 | 等级 | 行为 |
| --- | --- | --- | --- |
| 打开 | 打开页面或功能区 | A | 可立即导航 |
| 查看 | 打开页面并应用范围或状态 | A | 可立即导航并筛选 |
| 查找 | 打开页面并填写关键词 | A | 可立即导航并查询 |
| 预览 | 打开只读预览 | A | 找到唯一目标后打开预览 |
| 新建 | 创建业务记录 | B | 只打开并预填表单，用户手动提交 |
| 导入 | Excel 导入 | B | 只打开导入窗口，用户选择文件并确认 |
| 导出 | Excel 导出 | C | 打开导出预览，用户确认后生成文件 |
| 设置 | 定位系统设置 | B | 只打开并定位设置项，用户手动保存 |
| 创建 | 创建安全备份 | C | 显示确认弹窗后执行 |

执行等级的副作用契约：

| 等级 | 允许行为 | 确认前请求 | 禁止行为 |
| --- | --- | --- | --- |
| A | 导航、设置非敏感筛选、读取当前角色有权查看的数据 | 只允许目标页面原有的只读请求 | 写入业务数据、生成文件或打开危险确认 |
| B | 导航、打开表单或导入窗口、预填命令中明确提供的字段 | 不允许业务写请求 | 自动提交、自动选文件、自动保存设置 |
| C | 导航并展示导出预览或应用内确认 | 确认前只允许计算范围、数量或预览所需的只读请求 | 确认前生成文件、创建备份或产生其他写入 |
| D | 显示拒绝原因和安全的前往页面提示 | 不允许发送目标业务请求 | 导航到危险确认、预填危险操作或执行任何副作用 |

同一条命令在一次执行尚未结束时不得再次执行。Enter、鼠标点击和触摸操作必须共享同一个执行锁；C 级命令确认后只允许发出一次写入或下载请求。关闭 B、C 级界面必须回到命令执行前的业务状态，已经确认并完成的下载或备份不宣称可撤销。

## 6. 标准参数

### 6.1 时间范围

| 输入 | 解析结果 |
| --- | --- |
| 今天 | 当前本地日期 |
| 昨天 | 当前本地日期前一天 |
| 本周 | 当前自然周 |
| 上周 | 上一个自然周 |
| 本月 | 当前自然月 |
| 上月 | 上一个自然月 |
| 2026-08-28 | 指定日期 |
| 2026-08-01..2026-08-28 | 包含首尾日期的闭区间 |
| 2026年8月 | 2026-08-01 至 2026-08-31 |
| 2026年 | 2026-01-01 至 2026-12-31 |

开始日期晚于结束日期时应阻止执行，并提示“开始日期不能晚于结束日期”。

### 6.2 星期

规范值为：

    周一 周二 周三 周四 周五 周六 周日

允许输入“星期一”至“星期日”或“礼拜一”至“礼拜日”，解析后统一显示“周一”至“周日”。

### 6.3 值班状态

值班记录命令允许：

    待审核 未签退

具体签到或签退状态只在记录编辑界面显示：

    已通过 自动通过 已驳回

命令台不得直接把记录改为上述状态。

### 6.4 维修状态

维修事务命令允许：

    进行中 已完成 已取消

兼容输入“取消”，解析后统一显示“已取消”。

### 6.5 成员状态

成员名册命令允许：

    启用 停用

状态仅用于查看和筛选。命令台不得直接启用、停用或修改成员角色。

### 6.6 关键词

- 姓名、学号、维修编号和普通关键词均作为字符串处理。
- 包含空格的关键词必须使用引号。
- 关键词中的百分号、下划线和反斜线按普通字符处理。
- 建议列表不得显示不属于当前角色权限范围的个人资料。

| --- | --- |

| 成员名册 | 成员、人员、名册 |
| 个人资料 | 我的、个人、资料 |
| 维修事务 | 维修、维修记录 |
| 维修协议 | 协议、维修协议预览 |

## 8. 部长、会长和管理员通用命令

以下命令对部长、会长和管理员开放。

| 规范命令 | 等级 | 结果 |
| --- | --- | --- |
| `/ 打开 今日概览` | A | 打开今日概览 |
| `/ 打开 签到审核` | A | 打开待审核列表 |
| `/ 查看 值班记录 [范围]` | A | 打开值班记录并应用今天、昨天、本周、上周、本月、上月、指定日期或日期区间 |
| `/ 查看 值班记录 待审核` | A | 打开值班记录并筛选待审核 |
| `/ 查看 值班记录 未签退` | A | 打开值班记录并筛选未签退 |
| `/ 查找 值班记录 {关键词}` | A | 按姓名或学号查找记录 |
| `/ 查看 数据统计 [范围]` | A | 打开数据统计；支持今天、昨天、本周、上周、本月、上月、本年、指定日期或日期区间，缺省为本周 |
| `/ 导出 数据统计 [范围]` | C | 打开标准统计导出预览 |
| `/ 打开 维修事务` | A | 打开维修事务，缺省状态为进行中 |
| `/ 查看 维修事务 [{状态}] [范围]` | A | 按进行中、已完成或已取消及可选日期范围查看维修事务；状态缺省为进行中 |
| `/ 查找 维修事务 {关键词}` | A | 按编号、姓名、设备或故障关键词查找 |
| `/ 新建 维修事务` | B | 打开空白维修事务表单 |
| `/ 预览 维修协议 {维修编号}` | A | 找到唯一记录后打开协议预览 |
| `/ 打开 个人资料` | A | 打开当前账号个人资料 |

部长额外边界：

- 可以查看全部值班记录，但只能修改或删除本周普通成员和部长记录。
- 不能审核自己的记录，也不能处理会长或管理员记录。
- 可以新增和修改维修事务，不能导出或移入回收站。
- 数据统计只能使用标准统计导出，不能进入自定义导出。

## 9. 会长和管理员命令

以下命令只对会长和管理员开放。

### 9.1 值班和排班

| 规范命令 | 等级 | 结果 |
| --- | --- | --- |
| `/ 新建 值班记录` | B | 打开手动补录表单 |
| `/ 打开 排班管理` | A | 打开固定周排班 |
| `/ 查看 排班管理 今天` | A | 打开今天对应星期 |
| `/ 查看 排班管理 {星期}` | A | 打开周一至周日中的指定星期 |
| `/ 导入 排班管理` | B | 打开排班 Excel 导入窗口 |

命令台不能直接新增、替换或删除排班，只能打开对应界面。排班仍只能使用系统设置中已保存并启用的星期和时段。

### 9.2 成员

| 规范命令 | 等级 | 结果 |
| --- | --- | --- |
| `/ 打开 成员名册` | A | 打开成员名册 |
| `/ 查看 成员名册 {启用或停用}` | A | 按账号状态筛选 |
| `/ 查找 成员名册 {关键词}` | A | 按姓名或学号查找 |
| `/ 新建 成员` | B | 打开成员创建表单 |
| `/ 导入 成员名册` | B | 打开成员 Excel 导入窗口 |

## 12. 自动补全与排序

自动补全必须根据光标所在的活动参数逐级生成，不再对全部完整命令做统一模糊搜索。生成顺序：

1. 按当前会话角色过滤整棵命令树。
2. 只取得当前节点的合法直接子节点。
3. 当前参数的规范名称完全匹配。
4. 规范名称前缀匹配。
5. 当前参数的别名完全匹配或前缀匹配。
6. 当前参数名称包含匹配。
7. 在同一匹配等级内，当前页面相关节点优先，其次使用注册表中的稳定顺序。

自动补全必须完全在本地命令注册表中完成，输入、移动光标和切换建议时不得请求后端。只有用户明确执行完整命令后，才允许按执行等级发起目标页面的读取、预览或确认请求。

### 12.1 补全状态

| 状态 | 界面行为 | Enter 行为 |
| --- | --- | --- |
| 等待动作 | 展示当前角色允许的动作 | 不执行；明确选中后补全动作 |
| 等待对象 | 只展示该动作支持且当前角色可用的对象 | 不执行；明确选中后补全对象 |
| 等待参数 | 展示当前参数类型、合法枚举或输入要求 | 不执行；枚举可补全，自由文本等待输入 |
| 命令完整 | 展示结果摘要和执行等级 | 执行当前精确命令 |
| 参数错误 | 标出错误参数并展示该位置的合法建议 | 不执行 |
| 无权限 | 不展示受限数据，只显示稳定的无权限反馈 | 不执行 |

普通功能搜索的自由文本只能打开用户明确选择的功能结果，不能作为命令执行。命令模式中，完整且精确的当前输入优先于任何建议；没有经过方向键、Tab、点击或触摸明确选择的建议，不得替换用户输入。

进入新的参数层级后默认没有“已明确选择”的建议。Tab 可以接受排序第一的合法建议，方向键会建立明确的键盘选择；输入继续变化时应清除旧选择，避免沿用上一层的活动项。

### 12.2 建议内容

每次最多展示 6 条当前参数建议。每条建议包含：

- 当前参数的规范名称，不重复显示整条命令。
- 参数类型，例如“动作”“页面”“时间范围”“状态”。
- 一行直接结果，例如“查看本周值班记录”。
- 仅在选择后即可形成完整命令时显示执行等级，例如“打开”“预填”“需确认”。

输入框允许显示一段低对比度尾字补全，但仅在唯一的规范名称前缀匹配存在时出现。尾字不能进入输入值、读屏文本或表单提交；按 Tab、满足条件的右方向键或点击对应建议后才写入规范参数。

建议不得包含：

- 无权页面中的成员姓名、学号、联系电话等数据。
- 数据库表名、接口路径或内部枚举。
- 密码、令牌、备份绝对路径和安装目录。
- 删除、清空、恢复等可直接执行的危险入口。

普通搜索模式空输入时显示当前角色最多 5 条高频功能，不显示持久化搜索历史；输入 `/` 后改为展示命令树第一层动作，不继续显示完整高频命令。命令历史只允许在当前登录会话的内存中短暂存在，退出登录、刷新、角色变化或关闭应用后清除。历史不得用于自动补全姓名、学号、维修编号或其他业务关键词。

## 13. 执行流程

### 13.1 只读导航

1. 解析并规范化命令。
2. 检查当前角色是否允许访问目标页面。
3. 生成目标路由和筛选参数。
4. 导航后显示简短反馈，例如“已打开本周值班记录”。
5. 刷新页面后只通过 URL 恢复允许持久化的非敏感筛选。

允许进入 URL 的参数仅包括日期范围、状态、星期、分页和页面标签等不直接识别个人或具体事务的值。姓名、学号、电话、维修编号、自由关键词及其派生查询不得写入 URL、路由历史或持久化存储；这些参数只在当前页面内存中传递，刷新、退出登录或角色变化后清除。

### 13.2 新建、导入和设置

1. 检查权限。
2. 打开目标页面和对应弹窗或设置区域。
3. 仅预填命令中明确提供的字段。
4. 用户检查后手动提交。
5. 关闭弹窗时不应产生任何写操作。

### 13.3 导出和创建备份

1. 检查权限和参数。
2. 打开应用内确认或导出预览。
3. 显示范围、状态、预计数据源和文件类型。
4. 用户确认后调用现有业务流程。
5. 成功或失败使用统一 Toast 反馈。

导出继续遵守最多 50,000 行的业务上限，不得因使用命令台而绕过。

“导出预览”是行为要求，不强制新增独立页面。现有业务页面已经提供范围核对和应用内确认时，命令台应定位该入口并预设允许的非敏感筛选；没有确认流程时，不得由命令直接生成文件。导入培训参与人员时，必须先由页面明确选择培训场次，不能根据模糊关键词自动确定目标。

### 13.4 并发、重复执行与失败恢复

1. 同一命令台同一时间只允许一个执行流程处于进行中。
2. Enter、鼠标点击和触摸必须共享执行锁；重复操作不得产生重复导航、重复弹窗、重复下载或重复写入。
3. 新输入产生后，较早的异步解析或读取结果必须取消或忽略，不能覆盖较新的建议和反馈。
4. 导航失败时保留原命令；服务失败时只保留非敏感参数，敏感参数不得跨刷新或重新登录恢复。
5. B、C 级弹窗已经打开时，再次执行同一命令应聚焦现有弹窗，不得叠加第二个实例。
6. 会话过期、账号停用或角色变化时立即终止待执行流程，清除敏感输入并按现有会话流程处理。

### 13.5 目标匹配

- 姓名、学号或普通关键词出现多个结果时，只打开当前角色有权访问的过滤列表，不自动选中第一条记录。
- 维修协议预览必须使用完整维修编号并匹配唯一记录；不存在时不打开预览，出现异常重复时展示经过权限裁剪的选择列表。
- 建议和选择列表只显示完成区分所必需且当前角色原本可见的字段。同名成员优先显示脱敏学号，不增加联系电话等无关信息。
- 找不到目标时不得退化为更宽泛的写操作、默认选择或相似编号。

## 14. 禁止直接执行的命令

以下动作即使语法正确，也只能提示用户前往对应页面：

    删除 永久删除 清空 恢复 停用 启用 任命 重置密码
    通过审核 驳回审核 批量审核 修改记录 修改角色 修改值班时间

例如输入：

    / 删除 成员 1001

应返回：

    命令台不直接执行成员删除，请前往成员名册核对后操作。

不得把危险命令自动改写成相似的安全命令，也不得在提示后自动打开确认弹窗。

## 15. 错误反馈

| 场景 | 建议反馈 |
| --- | --- |
| 未识别动作 | 无法识别动作“处理”，可使用打开、查看、查找、新建、导入、导出或设置。 |
| 未识别对象 | 没有找到“事务中心”，请从建议中选择现有功能。 |
| 缺少关键词 | “查找成员”需要姓名或学号。 |
| 缺少维修编号 | 预览维修协议需要完整维修编号。 |
| 日期反转 | 开始日期不能晚于结束日期。 |
| 状态不支持 | 维修状态只支持进行中、已完成或已取消。 |
| 无权限 | 当前角色无权使用“成员名册”。 |
| 目标不存在 | 没有找到匹配的维修事务。 |
| 多个结果 | 找到多个结果，请补充编号或从列表中选择。 |
| 危险操作 | 命令台不直接执行该操作，请前往对应页面核对。 |
| 服务不可用 | 本机服务暂时不可用，命令和输入已保留，可稍后重试。 |
| 导出超限 | 导出结果超过 50,000 行，请缩小日期或状态范围。 |

错误发生后应保留原命令并选中第一个错误参数，便于用户直接修改。

## 16. 权限与安全

1. 前端只负责隐藏、提示和导航，后端权限仍是最终边界。
2. 命令列表和建议使用当前内存会话角色过滤，目标路由和业务接口仍由后端实时授权。收到 401 或 403、账号状态变化或会话刷新后，必须重新获取会话并立即重建建议；旧角色生成的活动建议和待执行命令全部失效。
3. 账号停用后，命令台和已有页面请求都必须失效。
4. 远程入口不得出现签到台、初始化和桌面控制命令。
5. 命令文本不写入普通操作日志；真正产生业务写入时，沿用对应业务操作日志。
6. 不持久化包含姓名、学号、电话、维修编号或其他业务关键词的命令历史，也不得把这些参数写入 URL、页面标题、普通日志或错误遥测。
7. 查找结果只显示当前页面原本允许当前角色查看的字段。
8. 命令不能绕过表单校验、导入上限、导出上限、确认弹窗和事务保护。
9. 命令参数不得拼接为 HTML、SQL、文件路径或系统命令。

## 17. 视觉与动效

- 命令模式沿用淡蓝色背景和现有输入框，不使用黑色终端外观。
- 普通搜索显示“功能”，命令模式显示“命令”状态标签；标签不使用高饱和胶囊样式。
- 输入框下方使用无卡片包裹的命令路径轨道显示“动作 › 对象 › 参数”，已经确认、当前活动和尚未填写的节点必须有清晰层级。
- 建议行主要显示当前参数及其直接结果，不重复渲染整条长命令；命令完整时改为结果摘要和执行提示。
- 唯一尾字补全使用低对比度文字叠放在输入光标之后，不能遮挡现有输入或造成宽度跳动。
- 进入命令模式、切换参数层级和完成命令时，输入框及页面主体尺寸保持稳定。
- 建议面板最大高度应稳定，结果多时仅面板内部滚动。
- 键盘选中、鼠标悬停、参数错误、命令完整和当前执行项必须使用不同但克制的状态。
- 命令执行成功后显示 1.5 至 2.5 秒反馈，不长期占据页面。
- 层级切换只使用透明度和不超过 4px 的小幅位移，不逐行播放动画，并遵守 `prefers-reduced-motion`。

具体颜色、尺寸、建议行和响应式要求以[前端视觉规范](前端视觉规范.md)中的“后台命令工作区”章节为准。

## 18. 无障碍

- 输入框必须有真实可访问名称，不能只依赖占位文字。
- 输入框使用标准 combobox 语义，并正确维护 `aria-controls`、`aria-expanded`、`aria-autocomplete="list"` 和 `aria-activedescendant`。
- 建议容器使用 listbox 语义，每条建议使用 option 语义；键盘活动项和鼠标悬停项在语义上保持独立，点击后才改变选中结果。
- 命令结果和错误使用礼貌级 live region 播报。
- 权限错误不能只通过颜色表达。
- 焦点进入命令台后必须可用键盘完整操作，关闭后恢复到原焦点。
- 中文输入法组合输入期间不得执行命令或移动建议。
- 接受补全后应播报已补全参数和下一个参数要求；命令完整时播报执行结果摘要和执行等级。
- Windows 125% 和 150% 缩放、浏览器 200% 缩放以及 680px 窄屏下不得出现文字与操作重叠。

## 19. 验收清单

### 19.1 解析

- 半角 `/` 命令前缀可识别，并且是唯一的命令模式入口。
- 连续空格、全角空格、引号关键词、对象别名和时间别名解析一致。
- 最长对象匹配、动作优先级和单词快捷命令没有歧义。
- 每个动作只生成合法对象，每个对象只生成注册表声明的下一参数。
- 移动光标后，活动参数、合法建议和错误位置同步变化。
- 缺少、重复、顺序冲突和未知参数不会被静默忽略。
- 日期范围、状态和星期使用规范值。
- 中文输入法组合输入期间，前缀、方向键和 Enter 不会触发命令。

### 19.2 权限

- 部长看不到排班、成员、培训、数据、设置和日志命令。
- 部长可以打开维修和统计，但不能导出维修或使用自定义导出。
- 会长可以使用排班、成员、培训、维修导出、数据和设置命令。
- 会长不能使用操作日志、维修回收站、备份恢复和管理员维护命令。
- 管理员可使用全部只读和预填命令。
- 直接输入无权命令时，后端请求仍不会发出。

### 19.3 安全操作

- 新建、导入和设置命令只打开界面，不自动提交。
- 导出和创建备份必须再次确认。
- 删除、清空、恢复、审核和账号状态修改不能通过命令直接执行。
- 业务写入继续产生原有操作日志，并保持事务一致性。
- C 级操作确认前没有文件生成或业务写请求，连续 Enter 和重复点击只执行一次。

### 19.4 交互

- `/`、Tab、方向键、Enter、Backspace 和 Esc 行为稳定，焦点位于其他可编辑控件时不会被全局前缀抢占。
- Tab 和满足条件的右方向键只补全当前参数；不完整命令按 Enter 不会提前执行。
- 接受建议只替换光标所在参数，不覆盖前后已经输入的合法内容。
- 点击最后一级建议只完成命令，不会立即执行。
- 角色变化后建议立即刷新，旧角色结果不可继续执行。
- 日期、状态、星期、分页和标签页等非敏感筛选可以通过 URL 恢复。
- 请求失败时保留输入，重试不会重复提交。
- 建议数量不超过 6 条，面板不会遮挡主要待办内容。
- 输入期间不请求后端，过期异步结果不会覆盖当前建议，已有弹窗不会被重复打开。

### 19.5 隐私与离线

- 命令台不持久化敏感查询历史。
- 姓名、学号、电话、维修编号和自由关键词不会进入 URL、页面标题或普通日志。
- 无权建议不显示个人数据摘要。
- 不加载互联网字体、脚本、搜索服务或自然语言模型。
- 桌面端、本机 Web 和远程后台使用同一离线解析规则。

### 19.6 数据驱动契约测试

命令注册表测试至少应为每条命令记录以下断言：

| 字段 | 验证内容 |
| --- | --- |
| 输入 | 半角 `/` 前缀、逐级补全路径、规范写法及允许别名 |
| 角色 | 允许角色、拒绝角色及权限变化后的失效行为 |
| 规范化结果 | 稳定命令 ID、规范动作、对象和参数 |
| 导航结果 | 目标路由、允许的 URL 参数和页面意图 |
| 执行等级 | A、B、C、D 及确认前允许的请求数量和类型 |
| 反馈 | 成功、参数错误、无权限、无结果和多结果文案 |

测试数据必须覆盖逐级节点过滤、光标中途编辑、Tab 与尾字补全、返回上一级、全角标点、引号、闰年与无效日期、重复参数、额外参数、别名冲突、连续执行、会话过期、角色变化、输入法组合、窄屏、缩放和 `prefers-reduced-motion`。任何敏感关键词进入建议、URL 或持久化历史都应直接判定为失败。

## 21. 预留扩展能力

以下命令方向需要新增或确认业务语义，不属于当前正式命令契约。运行时注册表、普通搜索和命令树在对应接口、权限、隐私与验收测试完成前不得展示这些节点。

| 预留命令 | 前置条件 | 预期等级 |
| --- | --- | --- |
| `/ 查看 我的值班 [范围]` | 明确“我的”仅绑定当前登录账号，并确认部长、会长和管理员的查询边界 | A |
| `/ 查看 维修事务 超期` | 定义维修期限、暂停时间、取消记录和超期计算规则，并由后端返回稳定筛选条件 | A |
| `/ 查看 排班管理 未排满` | 定义时段应排人数与“未排满”规则，保证只向会长和管理员开放 | A |
| `/ 查看 培训记录 我主讲的 [范围]` | 明确主讲人与账号的绑定方式，并确认历史姓名变更的匹配规则 | A |
| `/ 检查 数据状态` | 提供只读、脱敏的数据一致性检查接口，明确检查项和错误分级 | A |
| `/ 检查 最新备份` | 提供只读备份完整性验证，不自动创建、恢复、删除或下载备份 | A |

引入“检查”动作时必须同时更新动作注册、解析优先级、命令树、执行等级表和角色矩阵，不能把它作为“查看”的隐式别名。预留命令不得通过前端临时拼接现有查询实现，也不得在缺少后端权限校验时仅依赖前端隐藏。

## 22. 版本与变更治理

- 命令注册表必须声明独立的契约版本。纯显示文案调整可以保持版本不变；修改前缀、语法、命令 ID、参数含义、权限或执行等级时必须提升契约版本。
- 已发布的稳定命令 ID 不得复用给其他含义。对象或别名需要废弃时，应先保留一个明确的兼容周期并显示替代提示，再在后续版本移除。
- 新增、删除或调整命令时，必须同时检查命令注册、解析测试、角色权限测试、页面意图、本文档命令表和验收矩阵。
- 规范中未列出的命令属于预留能力，不得因为存在相似页面或后端接口而自动暴露。
- 命令入口、权限或副作用契约发生变化时，应在 `DEV_STATE.md` 记录当前实现状态；临时进度和发布说明不回写本规范。
