# 维修协议模板

正文参考 materials/inbox/协议模板 内两份 2024 原 Word，离线渲染核对。保留原条款、分节编号、灰色赔偿表和委托选项。个人电脑协议常规记录为两页；设备协议按用户要求只保留原两联的一联，填写区按实际内容增高，不重复第二联，打印仍使用 A4。

填写区按用户确认重新排布为送修登记、维修记录和手写签字：姓名/联系方式并排，设备型号/购买时间并排，故障/配件各一整行，个人协议保留原委托选项；负责人/完成时间并排，受理日期时间一整行。当前记录填写编号、送修人、设备、电话、附件、故障、负责人、完成时间和受理日期时间；购买时间未采集留空，委托项不自动勾选。送修人及维修人员签字、个人协议取机确认均留人工签名位，不自动生成签名。黑白正文、浅灰标签和细横线，不额外增加彩色卡片；第二页收紧页首及表格后的留白以容纳填写区，条款全文不变。

填写采用一次模板替换与 HTML 转义，不改变业务数据或数据库结构。字段过长时允许换行及内容自然增高，不裁切正文；两页检查针对当前常规测试记录，超长记录的实际打印需另行核对。
